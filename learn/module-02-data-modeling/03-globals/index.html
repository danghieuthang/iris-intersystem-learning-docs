    03 · Globals¶

    Exam Domain: T1 · Architecture — hiểu cấu trúc lưu trữ native của IRIS và cách thao tác dữ liệu không qua SQL/class

    Overview¶

    Globals là cấu trúc dữ liệu đa chiều, persistent của IRIS — lưu thẳng xuống database mà không cần class hay table. Đây là nền tảng bên dưới của mọi thứ trong IRIS: class %Persistent, SQL table, và cả Interoperability đều dùng globals ở backend.

    Basic Operations¶

    Globals bắt đầu bằng ký tự ^. Có thể có nhiều chiều (subscripts), tạo thành cây dữ liệu.

    // Gán
SET ^People(1, "Name") = "Alice"
SET ^People(1, "Age") = 30
SET ^People(2, "Name") = "Bob"

// Đọc
WRITE ^People(1, "Name")   // Alice

// Xóa một node
KILL ^People(1, "Age")

// Xóa toàn bộ subtree
KILL ^People(1)

    Traversal with $ORDER¶

    $ORDER duyệt các key ở một level theo thứ tự collation. Pattern chuẩn là vòng lặp FOR không điều kiện, QUIT khi hết key.

    SET id = ""
FOR {
    SET id = $ORDER(^People(id))
    QUIT:id=""
    WRITE id, ": ", ^People(id, "Name"), !
}

    Duyệt ngược (reverse): truyền -1 làm tham số thứ hai — $ORDER(^People(id), -1).

    Checking Existence with $DATA¶

    $DATA trả về số nguyên mô tả trạng thái của node:

    Giá trị Ý nghĩa
    0 Node không tồn tại
    1 Có data, không có children
    10 Không có data, có children
    11 Có cả data lẫn children 
    IF $DATA(^People(1)) {
    WRITE "Node exists", !
}

// Kiểm tra chính xác hơn
IF $DATA(^People(1)) = 11 {
    WRITE "Has data AND children", !
}

    MERGE & KILL¶

    // Copy toàn bộ subtree (deep copy)
MERGE ^Backup = ^People

// Xóa toàn bộ global
KILL ^People

// Xóa chỉ local variable (không ảnh hưởng global)
KILL localVar

    Globals vs SQL Table¶

    Globals SQL / %Persistent
    Tốc độ Rất nhanh Chậm hơn (overhead)
    Cấu trúc Linh hoạt, đa chiều Schema cố định
    Query $ORDER, $DATA SQL SELECT
    Khi dùng Cache, lookup, sparse data Business data, reporting

    Key Points¶

    • ✅ Globals bắt đầu bằng ^, tồn tại sau khi process kết thúc
    • ✅ %Persistent class thực ra lưu data vào globals ở backend
    • ✅ $ORDER(global, -1) để duyệt ngược
    • ⚠️ KILL ^Global xóa toàn bộ — không có undo
    • ⚠️ Globals không có schema — không có validation tự động
    • 💡 Dùng globals cho caching, lookup tables, counter — không dùng cho business data cần query phức tạp

    🖥️ Terminal Snippets¶

    // --- Xem tất cả keys level 1 của một global ---
SET key = ""
FOR { SET key = $ORDER(^People(key)) QUIT:key=""  WRITE key, ! }

// --- Đếm số records ---
SET count = 0, id = ""
FOR { SET id = $ORDER(^People(id)) QUIT:id=""  SET count = count + 1 }
WRITE "Total: ", count, !

// --- Copy và xóa ---
MERGE ^PeopleBackup = ^People
KILL ^People

// --- Kiểm tra node ---
WRITE $DATA(^People(1)), !
