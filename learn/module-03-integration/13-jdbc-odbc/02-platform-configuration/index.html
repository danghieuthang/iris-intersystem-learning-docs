    Platform Configuration¶

    Exam Domain: T3 · Data Retrieval — Windows vs UNIX ODBC setup, DSN storage, và command-line registration tools

    Overview¶

    JDBC thường khá portable giữa các OS. ODBC thì khác: cách lưu DSN, vị trí config file, và tool quản trị phụ thuộc mạnh vào platform. Đây là điểm exam rất thích hỏi vì dễ nhầm giữa Windows Registry và UNIX init files.

    Windows DSN Storage¶

    Trên Windows, ODBC DSN thường được quản lý qua ODBC Data Source Administrator và được lưu trong Registry.

    DSN type Typical location
    System DSN HKLM\SOFTWARE\ODBC\ODBC.INI
    User DSN HKCU\SOFTWARE\ODBC\ODBC.INI

    Why It Matters¶

    • System DSN dùng được cho nhiều users trên máy
    • User DSN chỉ có hiệu lực cho một user profile
    • Không nên nghĩ Windows dùng odbc.ini như UNIX

    UNIX ODBC Configuration Files¶

    Trên UNIX, ODBC config thường sống trong file text.

    File Purpose
    odbc.ini DSN definitions
    odbcinst.ini driver definitions
    odbcssl.ini TLS/SSL configuration names and certificate settings

    Nếu DSN cần TLS, DSN entry trong odbc.ini thường tham chiếu một cấu hình SSL/TLS nằm trong odbcssl.ini.

    ISC_SSLconfigurations¶

    Trên UNIX, biến môi trường này cho driver biết nơi tìm file odbcssl.ini.

    export ISC_SSLconfigurations=/opt/iris/odbc/odbcssl.ini

    Gotcha

    Nếu TLS config name đúng nhưng biến môi trường không trỏ tới file chứa cấu hình đó, connection vẫn fail.

    odbcinst¶

    odbcinst là utility command-line phổ biến để register driver hoặc DSN từ init file trên UNIX.

    Use Cases¶

    Need Tool
    register driver odbcinst
    register datasource odbcinst
    test a connection isql hoặc app client

    Fact

    isql thường dùng để test, không phải tool chính để cài DSN.

    DSN, File DSN, and DSN-less¶

    Mode Where config lives Typical fit
    Registry/File-backed DSN Registry hoặc odbc.ini admin-managed shared config
    File DSN .dsn text file portable shared datasource config
    DSN-less connection string ngay trong app deployment đơn giản, ít phụ thuộc OS setup

    DSN-less Example¶

    DRIVER={InterSystems IRIS ODBC35};SERVER=db.example.com;PORT=1972;DATABASE=MYAPP;UID=appuser;PWD=secret;

    Approach này hữu ích khi app containerized hoặc chạy ở môi trường không muốn pre-create DSN bằng tay.

    Cross-platform Decision Table¶

    Question Windows UNIX
    DSN được lưu ở đâu? Registry odbc.ini
    TLS config name nằm ở đâu? ODBC admin / installed config odbcssl.ini
    Tool đăng ký datasource GUI admin tool odbcinst
    Shared machine-wide datasource System DSN shared odbc.ini / system config

    Key Points¶

    • ✅ Windows DSN thường nằm trong Registry, không phải odbc.ini
    • ✅ UNIX thường dùng odbc.ini, odbcinst.ini, và odbcssl.ini
    • ✅ ISC_SSLconfigurations trỏ tới file TLS config của ODBC trên UNIX
    • ✅ odbcinst là tool quan trọng để register driver/data source trên UNIX
    • ⚠️ Đừng trộn lẫn vị trí config của Windows với UNIX
    • ⚠️ DSN-less không cần ODBC Administrator, nhưng app phải tự mang đủ connection parameters
    • 💡 Nếu câu hỏi nhắc Registry, gần như chắc đang nói về Windows ODBC

    🖥 Terminal Snippets¶

    # --- Point to the ODBC SSL configuration file on UNIX ---
export ISC_SSLconfigurations=/opt/iris/odbc/odbcssl.ini

# --- Register a driver or DSN from an ini file ---
odbcinst -i -s -f my-iris-dsn.ini
