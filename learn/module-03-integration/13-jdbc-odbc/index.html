    13 · JDBC, ODBC & External Connectivity¶

    Exam Domain: T3 · Data Retrieval — configuring secure JDBC/ODBC connections to InterSystems IRIS

    Overview¶

    InterSystems IRIS hỗ trợ kết nối từ ứng dụng bên ngoài thông qua JDBC (Java) và ODBC (nhiều ngôn ngữ khác nhau) để truy vấn SQL theo chuẩn công nghiệp. Cả hai đều sử dụng SuperServer của IRIS lắng nghe trên cổng 1972 (không phải cổng web 52773). TLS có thể được cấu hình để bảo mật kết nối trong môi trường production.

    Connection Architecture¶

    Java/Python App  →  JDBC Driver  →  IRIS SuperServer (port 1972)  →  IRIS Instance
External App     →  ODBC Driver  →  IRIS SuperServer (port 1972)  →  IRIS Instance
    • SuperServer: tiến trình nền của IRIS xử lý tất cả kết nối non-web (JDBC, ODBC, Native API, Telnet)
    • Default port: 1972 — có thể thay đổi trong file iris.cpf (tham số SuperServerPort)
    • Cổng này phải được mở trên firewall để JDBC/ODBC hoạt động từ bên ngoài

    JDBC Connection¶

    JDBC là cách phổ biến nhất để kết nối từ Java hoặc Python (JPype/Py4J) vào IRIS.

    Driver & JAR¶

    Thành phần Giá trị
    Driver class com.intersystems.jdbc.IRISDriver
    JAR file intersystems-jdbc-3.x.x.jar
    Vị trí JAR <IRIS install>/dev/java/lib/JDK18/
    Maven Central ❌ Không có — phải lấy từ bộ cài IRIS

    Connection URL Format¶

    jdbc:IRIS://hostname:1972/namespace

    Full Java Example¶

    // Load the IRIS JDBC driver
Class.forName("com.intersystems.jdbc.IRISDriver");

// Establish connection
Connection conn = DriverManager.getConnection(
    "jdbc:IRIS://localhost:1972/USER",
    "_SYSTEM",
    "SYS"
);

// Execute query
Statement stmt = conn.createStatement();
ResultSet rs = stmt.executeQuery("SELECT Name, Age FROM MyApp_Person");
while (rs.next()) {
    System.out.println(rs.getString("Name") + " - " + rs.getInt("Age"));
}

// Always close connection
conn.close();

    Kết nối có TLS¶

    jdbc:IRIS://hostname:1972/namespace?TLSEnabled=true&TLSKeyFile=/path/to/key&TLSCertificateFile=/path/to/cert&TLSCAFile=/path/to/ca

    ODBC Connection¶

    ODBC cho phép nhiều ngôn ngữ khác nhau (Python, C#, R, ...) kết nối vào IRIS thông qua driver chuẩn.

    Cài đặt Driver¶

    • IRIS ODBC Driver được cài riêng từ <IRIS>/bin/ODBCdriver
    • Sau khi cài, cấu hình DSN: ODBC Data Source Administrator → System DSN → Add → InterSystems IRIS ODBC Driver

    Thông tin DSN cần điền¶

    Trường Ví dụ
    Host localhost
    Port 1972
    Namespace USER
    Username _SYSTEM
    Password SYS

    Connection String¶

    DSN=MyIRIS;UID=username;PWD=password

    Python via pyodbc¶

    import pyodbc

# Connect using named DSN
conn = pyodbc.connect("DSN=MyIRIS;UID=_SYSTEM;PWD=SYS")
cursor = conn.cursor()
cursor.execute("SELECT Name, Age FROM MyApp_Person")
for row in cursor.fetchall():
    print(row.Name, row.Age)
conn.close()

    Secure Connections (TLS/SSL)¶

    IRIS hỗ trợ TLS cho JDBC, ODBC, và Native API connections. Đây là yêu cầu bắt buộc trong môi trường production (exam domain T4.2).

    Cấu hình phía Server¶

    1. Vào Management Portal → System → Security → SSL/TLS Configurations
    2. Tạo một SSL configuration mới (ví dụ: tên "client")
    3. Upload certificate và key files
    4. Bật TLS cho SuperServer trong System → Configuration → Memory and Startup

    JDBC TLS Parameters¶

    Parameter Mô tả
    TLSEnabled=true Bật TLS cho kết nối
    TLSKeyFile Đường dẫn đến private key của client
    TLSCertificateFile Đường dẫn đến certificate của client
    TLSCAFile Đường dẫn đến CA certificate để verify server

    ODBC TLS¶

    • Trong cấu hình DSN: bật checkbox "Enable TLS"
    • Cung cấp đường dẫn đến certificate files tương tự JDBC

    Mutual TLS (mTLS)¶

    • Yêu cầu cả server certificate (server xác thực với client) và client certificate (client xác thực với server)
    • Cung cấp cả TLSKeyFile và TLSCertificateFile trong connection URL/DSN

    SQL Security for External Access¶

    IRIS áp dụng cùng một security model cho SQL qua JDBC/ODBC như với SQL nội bộ (exam domain T3.3).

    Cấp quyền¶

    -- Grant SELECT privilege on a table to a user
GRANT SELECT ON MyApp.Person TO myuser;

-- Grant multiple privileges
GRANT SELECT, INSERT, UPDATE ON MyApp.Person TO myuser;

-- Revoke privilege
REVOKE SELECT ON MyApp.Person FROM myuser;

    Application Roles¶

    -- Create a role for read-only access
CREATE ROLE read_only_role;
GRANT SELECT ON MyApp.Person TO read_only_role;

-- Assign role to user
GRANT read_only_role TO myuser;

    Row-level Security¶

    • Dùng Views với mệnh đề WHERE dựa trên user đang đăng nhập
    • Ví dụ: CREATE VIEW MyView AS SELECT * FROM MyApp.Person WHERE Owner = CURRENT_USER

    Namespace Privilege¶

    • User cần có %DB_xxx privilege để truy cập namespace tương ứng
    • Cấu hình trong: Management Portal → System → Security → Users → [user] → Namespaces

    Connection Best Practices¶

    Các best practices cho kết nối JDBC/ODBC trong production (exam domain T4.2):

    Practice Chi tiết
    Dùng TLS Luôn bật TLS trong production — không truyền credentials plaintext
    Connection Pooling Dùng c3p0 hoặc HikariCP (Java) để tái sử dụng kết nối, giảm overhead
    Dedicated SQL User Tạo user riêng với quyền tối thiểu — không dùng _SYSTEM cho app
    Không hardcode credentials Dùng environment variables hoặc secret vault (HashiCorp, AWS Secrets Manager)
    Connection Timeout Đặt timeout để phát hiện kết nối bị đứt sớm
    Least Privilege Chỉ GRANT các quyền thực sự cần thiết (SELECT thay vì ALL)

    Key Points¶

    • ✅ JDBC URL format: jdbc:IRIS://host:port/namespace
    • ✅ ODBC và JDBC đều sử dụng SuperServer port 1972 — không phải web port 52773
    • ✅ TLS được cấu hình phía server trong Management Portal → Security → SSL/TLS Configurations
    • ✅ SQL privileges (GRANT/REVOKE) áp dụng đồng đều cho JDBC/ODBC user như với internal user
    • ⚠️ Cổng 1972 phải được mở trên firewall — nếu bị block, JDBC/ODBC sẽ không kết nối được
    • ⚠️ Không dùng _SYSTEM account cho production application connections — tạo dedicated user
    • ⚠️ JDBC driver JAR không có trên Maven Central — phải lấy từ bộ cài IRIS (<IRIS>/dev/java/lib/)
    • 💡 Cho exam: nhớ format jdbc:IRIS://host:1972/namespace và tham số TLSEnabled=true
    • 💡 Dùng connection pooling (HikariCP) trong Java để tránh tạo kết nối mới cho mỗi request

    🖥️ Terminal Snippets¶

    // --- Check SuperServer port (run in %SYS namespace) ---
ZNSPACE "%SYS"
WRITE ##class(Security.System).Get("SuperServerPort"), !

// --- Grant SELECT privilege to a SQL user ---
DO ##class(%SYSTEM.SQL.Security).GrantPrivilege("SELECT", "MyApp_Person", "sqlusr")

// --- Create a dedicated SQL user (run in %SYS) ---
ZNSPACE "%SYS"
SET props("Password") = "SYS123"
SET props("Roles") = "%DB_USER"
DO ##class(Security.Users).Create("sqlusr", "", .props)

// --- List all SSL/TLS configurations ---
ZNSPACE "%SYS"
SET rs = ##class(%ResultSet).%New("Security.SSLConfigs:List")
DO rs.Execute()
WHILE rs.Next() {
    WRITE rs.Get("Name"), !
}

// --- Test JDBC connectivity from ObjectScript (using %Net.Remote.Gateway) ---
SET gw = ##class(%Net.Remote.Gateway).%New()
SET sc = gw.%Connect("localhost", 1972, "USER")
IF $$$ISERR(sc) { WRITE $SYSTEM.Status.GetErrorText(sc), ! }
