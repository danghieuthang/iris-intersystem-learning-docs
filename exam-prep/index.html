    Chiến Lược Ôn Thi¶

    Ưu tiên

    Domain T1.2 (Data Structures) và T3 (SQL) chiếm tỉ trọng cao — tập trung ở đây trước.

    Lưu ý với MR

    Câu Multiple Response: phải chọn đúng tất cả đáp án đúng mới được điểm. Không có điểm một phần.

    Tài liệu trong phòng thi

    Được dùng docs.intersystems.com nhưng thời gian rất hạn chế — cần thuộc các keyword, method name cốt lõi.

    Checklist Trước Thi¶

    • [ ] Nắm rõ 3 loại class: Persistent / Registered / Serial
    • [ ] Phân biệt Dynamic SQL vs Embedded SQL vs Class Query
    • [ ] Biết khi nào dùng Stream thay vì String
    • [ ] Hiểu %Status và cách check lỗi
    • [ ] Biết cấu trúc REST API với %CSP.REST
    • [ ] Nắm các loại Index: Standard / Unique / Bitmap / Bitslice
    • [ ] Làm ít nhất 1 quiz cho mỗi topic
