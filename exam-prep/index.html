    Chiến Lược Ôn Thi¶

    Ưu tiên theo domain

    • T1 Architecture: tập trung T1.2 (data structures) và T1.1 (namespaces/mirroring) — hay ra thi
    • T3 Data Retrieval: Python strategies (T3.1) và Advanced SQL (T3.3) — nhiều câu hỏi thực tiễn
    • T4 Code: Transactions/Journaling (T4.3) và Locking (T4.4) — hay ra câu tricky

    Lưu ý với MR

    Câu Multiple Response: phải chọn đúng tất cả đáp án đúng mới được điểm. Không có điểm một phần.

    Tài liệu trong phòng thi

    Được dùng docs.intersystems.com nhưng thời gian rất hạn chế — cần thuộc các keyword, method name cốt lõi.

    Checklist Trước Thi¶

    T1 — Architecture¶

    • Phân biệt Namespace (logical) vs Database (physical file)
    • Nắm rõ 3 loại class: Persistent / Registered / Serial
    • Biết các loại Index: Standard / Unique / Bitmap / Bitslice
    • Hiểu mirroring (HA) vs sharding (scalability)
    • Biết Global Mappings và khi nào dùng
    • Hiểu vai trò CPF file trong CI/CD

    T2 — Development Lifecycle¶

    • Nắm các profiling tools: ^%SYS.MONLBL, ^SystemPerformance, ^PERFSAMPLE
    • Biết cách JOB command spawn background process
    • Phân biệt containers vs IRIS Installer deployment
    • Hiểu source control integration (git-source-control)
    • Biết implications khi import updated persistent class

    T3 — Data Retrieval¶

    • Phân biệt 4 Python strategies: Embedded / Native API / DB-API / External
    • Biết JDBC URL format: jdbc:IRIS://host:1972/namespace
    • Phân biệt Dynamic SQL vs Embedded SQL vs Class Query
    • Biết cách đọc query plan (EXPLAIN)
    • Hiểu TuneTable và SQL Statement Index
    • Nắm implicit join -> syntax
    • Biết cấu trúc REST API với %CSP.REST + Specification-first

    T4 — Code¶

    • Hiểu %Status và TRY/CATCH error handling
    • Nắm TSTART / TCOMMIT / TROLLBACK và $TLEVEL
    • Hiểu journaling inside vs outside transaction
    • Biết LOCK +/- với timeout và $TEST
    • Phân biệt row lock vs table lock
    • Biết $ZSTORAGE và system limits (max string ~3.6MB)
    • Làm ít nhất 1 quiz cho mỗi topic
