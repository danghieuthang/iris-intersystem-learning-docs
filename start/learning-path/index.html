    🚀 Learning Path¶

    Lộ trình học để đạt chứng chỉ InterSystems IRIS Development Professional.

    🎯 Mục Tiêu¶

    Chứng chỉ

    InterSystems IRIS Development Professional — kiểm tra khả năng thiết kế, xây dựng và triển khai ứng dụng trên nền tảng IRIS.
    Số câu 65 (62 tính điểm + 3 unscored)
    Thời gian 2.5 giờ
    Điểm đậu 65%
    Loại câu ~70% MC (1 đáp án) · ~30% MR (chọn tất cả đúng)
    Phiên bản IRIS v2024.1+
    Tài liệu Được mang vào nhưng không đủ thời gian tra nhiều

    📋 Chi Tiết Từng Bước¶

    Bước 1 · Chuẩn Bị Môi Trường¶

    ⏱ ~30 phút · Làm 1 lần duy nhất

    • Cài Docker Desktop + VS Code
    • Clone repo, chạy docker compose up -d
    • Kết nối VS Code với IRIS qua ObjectScript extension
    • Mở được Management Portal và IRIS Terminal

    📄 Hướng dẫn chi tiết → Setup Guide

    Bước 2 · Nền Tảng Hệ Thống¶

    ⏱ ~3–4 ngày · Tương ứng Domain T1.1 + T4 cơ bản

    Topic Tài liệu Điểm cần nắm
    Architecture Namespaces, databases, mirroring, CPF Namespace vs Database, global mappings
    ObjectScript Basics Variables, control flow, error handling %Status, TRY/CATCH, $$$OK

    Tại sao Architecture trước?

    Ngay từ khi chạy IRIS, bạn đang ở namespace USER. Hiểu namespace/database trước sẽ giúp mọi topic sau dễ hơn — globals lưu ở đâu, class compile vào database nào, REST app gắn vào đâu.

    Bước 3 · Mô Hình Dữ Liệu¶

    ⏱ ~1.5 tuần · Tương ứng Domain T1.2 + T3.3

    Topic Tài liệu Điểm cần nắm
    Classes & Objects Persistent, JSON, indices, streams Persistent vs Registered vs Serial
    Globals Global storage, $ORDER, $DATA Quan hệ Global ↔ Object ↔ SQL
    SQL Dynamic SQL, Embedded SQL, Class Query Khi nào dùng cái nào
    Advanced SQL Query plans, statistics, implicit join ->, SQL security EXPLAIN, TuneTable, GRANT

    Thứ tự học

    Classes → Globals → SQL. Khi học SQL, bạn sẽ thấy MyApp_Person chính là global ^MyApp.PersonD — liên hệ này rất quan trọng.

    Bước 4 · API & Kết Nối¶

    ⏱ ~1 tuần · Tương ứng Domain T3.1 + T3.2 + T3.4

    Topic Tài liệu Điểm cần nắm
    REST API %CSP.REST, Dispatch class, Spec-first, IAM Route mapping, OpenAPI
    Python with IRIS Embedded Python, Native API, DB-API 4 strategies + when to use
    JDBC/ODBC JDBC URL, ODBC DSN, TLS/SSL config jdbc:IRIS://host:1972/namespace

    Python — điểm mới trong đề thi

    T3.1 hỏi về 4 Python strategies. Nắm rõ sự khác biệt giữa Embedded Python (in-process) vs Native API (pyirisnative) vs DB-API (SQL via dbapi).

    Bước 5 · Vận Hành & Code¶

    ⏱ ~1 tuần · Tương ứng Domain T2 + T4.2–T4.4

    Topic Tài liệu Điểm cần nắm
    Dev Tools & CI/CD ^%SYS.MONLBL, JOB, Docker, CPF MERGE, source control Profiling tools, deployment options
    Transactions & Locking TSTART/TCOMMIT, journaling, LOCK +/-, row vs table $TLEVEL, journaling inside vs outside tx
    Security Roles, Resources, Auth modes, encryption Authentication vs Authorization

    Transactions hay ra câu tricky

    Phân biệt journaling inside vs outside transaction là điểm hay bị nhầm. Và %Save() failure KHÔNG tự động rollback.

    Bước 6 · Tích Hợp & Kiểm Thử¶

    ⏱ ~1 tuần · Tương ứng Domain T1.1.8 + T2.2.3

    Topic Tài liệu Điểm cần nắm
    Interoperability BS → BP → BO, Messages, Adapters Flow message, khi nào Sync vs Async
    Unit Testing %UnitTest.TestCase, assert methods Cách viết và chạy test trong CI/CD

    Bước 7 · Ôn Thi¶

    ⏱ ~1 tuần trước thi

    • Làm quiz cho từng topic (mục 🧪 Practice)
    • Xem lại Cheatsheets cho các syntax hay quên
    • Ghi lại vào Mistakes những chỗ làm sai trong quiz
    • Đọc lại Checklist trước thi

    Chiến lược thi

    Tài liệu được mang vào phòng thi — tập trung nhớ tên method, tên class, cú pháp cốt lõi thay vì học thuộc lòng chi tiết. Tra nhanh docs khi cần xác nhận.
