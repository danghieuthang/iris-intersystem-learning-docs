    ObjectScript · Cheatsheet¶

    Syntax¶

    SET x = 10                              ; assign
SET ^G = "val"                          ; global (persists)
FOR i = 1:1:10 { WRITE i, ! }          ; from:step:to
SET key = ""
FOR { SET key = $ORDER(arr(key))  QUIT:key=""  WRITE arr(key), ! }

SET list = $LB("a","b","c")            ; $LIST
WRITE $LG(list, 1)                     ; get element (1-indexed)
WHILE $LISTNEXT(list, ptr, val) { }    ; efficient iterate

SET $PIECE(csv, ",", 2) = "new"        ; replace piece in-place
WRITE $EXTRACT(str, *)                 ; last char
WRITE $FIND(str, "x")                  ; pos AFTER "x", not at

    Key Functions¶

    Function Returns
    $PIECE(s, d, n) nth delimited piece
    $EXTRACT(s, from, to) substring by position
    $FIND(s, t) position after target
    $LENGTH(s, d) number of pieces
    $DATA(node) 0/1/10/11
    $ORDER(arr(key)) next key ("" = done)
    $LB(...) / $LG(list,n) create / get list element
    $LISTFIND(list, val) index (0 = not found)

    Highlight Token Cheatsheet¶

    Command¶

    Các command là các lệnh ObjectScript chạy trực tiếp trong routine/method body.

    Token Ví dụ
    SET SET x = 1
    WRITE WRITE name, !
    DO DO ..Validate()
    KILL KILL arr
    MERGE MERGE ^Backup = ^Source
    NEW NEW sc
    LOCK LOCK +^MyGlobal(1)
    TSTART / TCOMMIT / TROLLBACK transaction commands

    Keyword¶

    Các keyword thiên về control flow, class syntax, modifiers, và embedded SQL keywords.

    Token Ví dụ
    IF / ELSE / ELSEIF IF age>18 { ... }
    TRY / CATCH / THROW exception flow
    Class / Extends Class MyApp.Person Extends %Persistent
    Property / Method / ClassMethod class members
    Parameter / Query / Trigger UDL keywords
    SELECT / FROM / WHERE embedded SQL in &sql(...)
    INSERT / UPDATE / DELETE SQL data change keywords

    Built-in¶

    Built-in thường là system function hoặc command-like built-in token.

    Token Ví dụ
    $PIECE $PIECE(csv, ",", 1)
    $ORDER $ORDER(arr(key))
    $DATA $DATA(^G(1))
    $SYSTEM $SYSTEM.Status.GetErrorText(sc)
    ##class(...) ##class(MyApp.Person).%New()
    WRITE / READ / OPEN / USE runtime built-in commands

    Type¶

    Type thường là class name hoặc datatype.

    Token Ví dụ
    %Persistent Extends %Persistent
    %String Property Name As %String
    %Integer Property Age As %Integer
    MyApp.Person custom class type
    %SQLQuery As %SQLQuery

    Member¶

    Member là property, instance reference, global/member-like token.

    Token Ví dụ
    %Name %request, %response, %SQLCODE
    ..Property ..Name
    ..Method() ..Validate()
    ^Global ^MyApp.PersonD(1)
    :hostVar &sql(SELECT Name INTO :name ...)

    Operator¶

    Operator là các ký hiệu phép toán, so sánh, hoặc special operator.

    Token Ví dụ
    = SET x = 1
    < / > / <= / >= comparisons
    + / - / * / ** arithmetic
    ? IF phone?10N
    ! newline in WRITE
    @ indirection
    ^ global indicator

    Punctuation¶

    Punctuation là các ký hiệu cấu trúc, delimiter, và bracket.

    Token Ví dụ
    ( ) method call / expression grouping
    { } block syntax
    [ ] pattern / bracket forms
    , argument separator
    : postconditional / FOR from:step:to
    . / .. / ... dotted syntax / instance access
    _ string concatenation

    Error Handling¶

    SET sc = obj.%Save()
IF $$$ISERR(sc) { WRITE $SYSTEM.Status.GetErrorText(sc) }

TRY {
    $$$ThrowOnError(sc)     ; throw if $$$ISERR
} CATCH ex {
    WRITE ex.DisplayString() ; works on ALL exception types
}

RETURN $$$ERROR($$$GeneralError, "message")
    Macro
    $$$OK success (= 1)
    $$$ISERR(sc) is error?
    $$$ThrowOnError(sc) throw if error

    ⚠️ Gotchas¶

    • DO obj.%Save() silently fails — always SET sc = obj.%Save()
    • $FIND returns position after target, not at target
    • $ORDER(arr("")) = first key · "" returned = no more keys
    • Arrays must pass ByRef: Method(ByRef pArr) → call as ..Method(.arr)
    • $LIST binary encoding — never WRITE raw list
    • ex.AsStatus() / ex.%AsStatus() may fail on %Exception.SystemException → use ex.DisplayString()

    🎯 Exam¶

    • $DATA values: 0 none · 1 data · 10 children only · 11 both
    • $ORDER traversal: start with "", quit when returns ""
    • Pattern match: ?10N = 10 digits · ?1.A = 1+ letters · E = any char
    • $PIECE is 1-indexed · $EXTRACT(str, *) = last char
    • Highlight taxonomy useful for docs/quiz app: command · keyword · built-in · type · member · operator · punctuation
