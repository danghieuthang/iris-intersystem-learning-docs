    07 — Unit Testing¶

    📌 Key Concepts¶

    Cấu Trúc Test Class¶

    Class MyApp.Test.PersonTest Extends %UnitTest.TestCase
{

/// Chạy trước mỗi test method
Method OnBeforeAllTests() As %Status
{
    // Setup chung cho tất cả tests
    RETURN $$$OK
}

/// Test method — BẮT BUỘC bắt đầu bằng "Test"
Method TestCreatePerson() As %Status
{
    SET person = ##class(MyApp.Person).%New()
    SET person.Name = "Alice"
    SET person.Age = 30

    SET sc = person.%Save()
    DO $$$AssertStatusOK(sc, "Save should succeed")
    DO $$$AssertNotEquals(person.%Id(), "", "ID should be assigned")

    RETURN $$$OK
}

Method TestPersonGreet() As %Status
{
    SET person = ##class(MyApp.Person).%New()
    SET person.Name = "Bob"

    DO $$$AssertEquals(person.Greet(), "Hello, Bob", "Greet should return correct string")

    RETURN $$$OK
}

}

    Assertions Hay Dùng¶

    $$$AssertEquals(actual, expected, message)
$$$AssertNotEquals(actual, notExpected, message)
$$$AssertTrue(condition, message)
$$$AssertFalse(condition, message)
$$$AssertStatusOK(status, message)
$$$AssertStatusNotOK(status, message)

    Chạy Tests¶

    ; Từ Terminal/IRIS Studio
DO ##class(%UnitTest.Manager).RunTest("MyApp.Test.PersonTest")

; Chạy toàn bộ package
DO ##class(%UnitTest.Manager).RunTest("MyApp.Test")

; Với verbose output
DO ##class(%UnitTest.Manager).RunTest("MyApp.Test", "/noload/norecursive")

    Xem Kết Quả¶

    • Management Portal → System > Tools > Unit Test Manager
    • Hoặc xem output trực tiếp trên Terminal

    ❓ Những Điểm Cần Nhớ¶

    • Test class bắt buộc extend %UnitTest.TestCase
    • Test method bắt buộc bắt đầu bằng Test (phân biệt hoa/thường)
    • Mỗi test method trả về %Status
    • Cleanup data sau test để không ảnh hưởng test khác
