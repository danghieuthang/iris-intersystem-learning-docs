    String Operations¶

    Exam Domain: T4 · Code — thao tác chuỗi là kỹ năng coding cơ bản

    Overview¶

    ObjectScript cung cấp bộ hàm chuỗi phong phú tích hợp sẵn: $PIECE để tách/ghép theo delimiter, $EXTRACT để cắt theo vị trí, $TRANSLATE để thay thế ký tự, và Pattern Matching như regex đơn giản. Hầu hết hàm đều hỗ trợ cả đọc lẫn ghi (SET vào left-hand side).

    Concatenation¶

    ; Dùng toán tử _ (underscore)
SET first = "Hello"
SET last  = " World"
SET full  = first _ last
WRITE full   ; Hello World

; Nối trực tiếp với số (auto-convert)
SET msg = "Count: " _ 42
WRITE msg    ; Count: 42

    $PIECE — Split & Join¶

    $PIECE là function quan trọng nhất trong string operations — làm việc với chuỗi có delimiter:

    ; $PIECE(string, delimiter, from, to)
SET csv = "Alice,30,Engineer,Hanoi"

; Lấy phần tử thứ n
WRITE $PIECE(csv, ",", 1)      ; Alice
WRITE $PIECE(csv, ",", 2)      ; 30
WRITE $PIECE(csv, ",", 3)      ; Engineer

; Lấy từ n đến m
WRITE $PIECE(csv, ",", 2, 3)   ; 30,Engineer

; Dùng $PIECE để SET — thay thế phần tử
SET $PIECE(csv, ",", 2) = 31
WRITE csv   ; Alice,31,Engineer,Hanoi

    $EXTRACT — Substring by Position¶

    SET str = "InterSystems"

; $EXTRACT(string, pos)         — lấy 1 ký tự
; $EXTRACT(string, from, to)    — lấy substring
WRITE $EXTRACT(str, 1)          ; I
WRITE $EXTRACT(str, 1, 5)       ; Inter
WRITE $EXTRACT(str, 6)          ; S (đến hết)

; SET với $EXTRACT — thay thế ký tự
SET $EXTRACT(str, 1, 5) = "Hyper"
WRITE str   ; HyperSystems

    $FIND — Finding Position¶

    ; $FIND(string, target, start)
; Trả về vị trí NGAY SAU target (không phải vị trí bắt đầu!)
SET str = "Hello World Hello"

WRITE $FIND(str, "Hello")      ; 6 (sau ký tự thứ 5)
WRITE $FIND(str, "Hello", 6)   ; 18 (tìm từ vị trí 6)
WRITE $FIND(str, "xyz")        ; 0 (không tìm thấy)

; Tìm vị trí bắt đầu thực sự:
SET pos = $FIND(str, "World") - $LENGTH("World") - 1  ; = 6

    $TRANSLATE — Character Replacement¶

    ; $TRANSLATE(string, from, to)
; Thay từng ký tự trong 'from' bằng ký tự tương ứng trong 'to'
SET str = "Hello World"

WRITE $TRANSLATE(str, "aeiou", "AEIOU")   ; HEllO WOrld
WRITE $TRANSLATE(str, "lo", "LO")         ; HeLLO WOrLd

; Xóa ký tự — 'to' ngắn hơn 'from'
WRITE $TRANSLATE(str, " ")                ; HelloWorld (xóa khoảng trắng)

    $LENGTH — Length and Counting¶

    SET str = "Hello,World,IRIS"

; Độ dài chuỗi
WRITE $LENGTH(str)               ; 16

; Đếm số phần tử phân cách bởi delimiter
WRITE $LENGTH(str, ",")          ; 3  ← dùng để biết có bao nhiêu piece

    Pattern Matching¶

    Thay thế đơn giản cho regex trong nhiều trường hợp:

    ; Cú pháp: string ? pattern
; Ký hiệu: nL = n chữ cái, nN = n số, nE = n ký tự bất kỳ, nP = n dấu câu

; Kiểm tra số điện thoại đơn giản (10 chữ số)
IF phone?10N {
    WRITE "Hợp lệ"
}

; Kiểm tra có phải chỉ gồm chữ cái
IF name?1.A {      ; 1 hoặc nhiều chữ cái (A = alpha = L hoặc U)
    WRITE "Chỉ có chữ cái"
}

; Email đơn giản
IF email?1.E1"@"1.E1"."1.E {
    WRITE "Có vẻ là email"
}
    Ký hiệu Ý nghĩa
    N Chữ số (0-9)
    U Chữ hoa
    L Chữ thường
    A Chữ cái (U hoặc L)
    E Bất kỳ ký tự nào
    P Dấu câu
    n. n hoặc nhiều hơn

    8. Trim & Padding¶

    ; Không có hàm trim built-in — dùng kết hợp
SET str = "  hello  "

; Trim trái (xóa khoảng trắng đầu)
WHILE $EXTRACT(str, 1) = " " { SET str = $EXTRACT(str, 2, *) }

; Trim phải
WHILE $EXTRACT(str, *) = " " { SET str = $EXTRACT(str, 1, *-1) }

; $EXTRACT(str, *) = ký tự cuối cùng
; $EXTRACT(str, n, *) = từ n đến cuối

; Padding phải (right-pad đến độ dài n)
SET padded = $JUSTIFY("hello", 10)   ; "     hello" (right-justify)

    Key Points¶

    • ✅ $PIECE(str, delim, n) là function phổ biến nhất khi làm việc với CSV/delimited data
    • ✅ SET $PIECE(str, ",", 2) = "new" cho phép thay thế piece in-place
    • ✅ $LENGTH(str, delim) đếm số pieces (không phải độ dài) khi có delimiter
    • ⚠️ $FIND trả về vị trí sau target, không phải vị trí bắt đầu — phải trừ đi $LENGTH(target)
    • ⚠️ ObjectScript không có trim built-in — phải dùng vòng lặp hoặc $ZSTRIP (IRIS specific)
    • 💡 $TRANSLATE(str, " ") là cách nhanh nhất để xóa tất cả khoảng trắng

    🖥️ Terminal Snippets¶

    WRITE "Year: ", $PIECE(line,",",1), ! WRITE "Name: ", $PIECE(line,",",2), ! WRITE "Role: ", $PIECE(line,",",3), !

    ; Đếm pieces WRITE "Count: ", $LENGTH(line,","), !

    ; $TRANSLATE — xóa khoảng trắng SET messy = "H e l l o" WRITE $TRANSLATE(messy," "), ! ; Hello

    ; Pattern matching SET phone = "0912345678" IF phone?10N { WRITE "Valid phone!", ! } ```
