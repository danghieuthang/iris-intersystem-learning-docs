    Arrays¶

    Exam Domain: T1 · Architecture — arrays là cấu trúc dữ liệu core, nền tảng của globals

    Overview¶

    Array trong ObjectScript là cấu trúc dữ liệu đa chiều, sparse, không cần khai báo trước. Chúng là nền tảng của globals và được dùng rộng rãi để lưu trữ tạm thời trong process. Cú pháp và hàm thao tác ($ORDER, $DATA, MERGE) giống nhau cho cả local array và global.

    Local Arrays¶

    Khác với ngôn ngữ khác, array trong ObjectScript là đa chiều, sparse (không cần liên tục) và không cần khai báo trước.

    ; Gán giá trị
SET arr(1) = "Alice"
SET arr(2) = "Bob"
SET arr(3) = "Charlie"

; Đa chiều
SET person(1, "name") = "Alice"
SET person(1, "age")  = 30
SET person(2, "name") = "Bob"
SET person(2, "age")  = 25

; Sparse — index không cần liên tục
SET data(1)   = "first"
SET data(100) = "hundredth"   ; không cần data(2..99)
SET data("key") = "string key cũng được"

    Traversal with $ORDER¶

    $ORDER trả về key tiếp theo — dùng để iterate:

    ; Duyệt 1 chiều
SET key = ""
FOR {
    SET key = $ORDER(arr(key))
    QUIT:key=""
    WRITE key, ": ", arr(key), !
}

; Duyệt 2 chiều (nested)
SET id = ""
FOR {
    SET id = $ORDER(person(id))
    QUIT:id=""
    WRITE "Person ", id, !

    SET field = ""
    FOR {
        SET field = $ORDER(person(id, field))
        QUIT:field=""
        WRITE "  ", field, ": ", person(id, field), !
    }
}

    💡 $ORDER với argument rỗng "" trả về key đầu tiên.
    Khi không còn key nào, trả về "".

    Reverse Traversal¶

    ; $ORDER(arr(key), -1) = key TRƯỚC key hiện tại
SET key = $ORDER(arr(""), -1)   ; key cuối cùng
FOR {
    QUIT:key=""
    WRITE key, ": ", arr(key), !
    SET key = $ORDER(arr(key), -1)
}

    Checking Nodes with $DATA¶

    ; Giá trị trả về:
; 0  = node không tồn tại
; 1  = có data, không có children
; 10 = không có data, có children (intermediate node)
; 11 = có cả data lẫn children

SET arr(1) = "value"
SET arr(1, "sub") = "child"

WRITE $DATA(arr(1))      ; 11
WRITE $DATA(arr(1,"sub")); 1
WRITE $DATA(arr(99))     ; 0

; Dùng trong IF
IF $DATA(arr(key)) {
    WRITE "Tồn tại: ", arr(key), !
}

    Deleting with KILL¶

    SET arr(1) = "a"
SET arr(1, "sub") = "b"
SET arr(2) = "c"

KILL arr(1)       ; xóa arr(1) VÀ toàn bộ subtree arr(1,...)
KILL arr          ; xóa toàn bộ array

; Xóa chỉ data, giữ lại node (ít dùng)
; Không có lệnh riêng — dùng KILL rồi set lại children nếu cần

    Merging Arrays¶

    ; Copy toàn bộ array
MERGE dest = source

; Copy một subtree
MERGE dest("copy") = source(1)

; Dùng để truyền array vào method
Method ProcessData(ByRef pData)
{
    SET key = ""
    FOR {
        SET key = $ORDER(pData(key))
        QUIT:key=""
        // xử lý pData(key)
    }
}
// Gọi:
DO ..ProcessData(.myArray)   ; chú ý dấu . trước biến

    ⚠️ Truyền array vào method/function phải dùng ByRef và gọi với dấu . (pass by reference).

    Counting Elements¶

    ObjectScript không có hàm length(arr) — phải đếm thủ công hoặc tự track:

    ; Cách 1: Đếm khi duyệt
SET count = 0
SET key = ""
FOR {
    SET key = $ORDER(arr(key))
    QUIT:key=""
    SET count = count + 1
}
WRITE "Count: ", count, !

; Cách 2: Dùng node đặc biệt để track count
SET arr = 0           ; arr (không subscript) = count
SET arr = arr + 1
SET arr(arr) = "new item"
WRITE "Count: ", arr, !

    Arrays vs Globals¶

    Local Array Global
    Ký hiệu arr(1) ^arr(1)
    Lưu trữ Trong memory (process) Trên disk (persistent)
    Tồn tại sau khi process kết thúc ❌ ✅
    Dùng $ORDER, $DATA, MERGE ✅ ✅

    Key Points¶

    • ✅ Array index bắt đầu từ bất kỳ giá trị nào — số, chuỗi, âm đều được (sparse)
    • ✅ $ORDER(arr(""), -1) trả về key cuối cùng
    • ✅ $DATA = 11 nghĩa là node vừa có data vừa có children
    • ⚠️ Truyền array vào method phải dùng ByRef và gọi với dấu . — DO ..Method(.myArr)
    • ⚠️ KILL arr(1) xóa cả subtree — không có cách undo
    • 💡 Dùng array để lưu tạm dữ liệu trong process, dùng Global (^) để persist

    🖥️ Terminal Snippets¶

    SET fruit("a") = "Apple" SET fruit("b") = "Banana" SET fruit("c") = "Cherry" SET k = "" FOR { SET k=$ORDER(fruit(k)) QUIT:k="" WRITE k,": ",fruit(k),! }

    ; Kiểm tra $DATA SET x(1)="val" SET x(1,"child")="sub" WRITE "$DATA(x(1)) = ", $DATA(x(1)), ! ; 11 WRITE "$DATA(x(2)) = ", $DATA(x(2)), ! ; 0

    ; Merge MERGE copy = fruit KILL fruit SET k = "" FOR { SET k=$ORDER(copy(k)) QUIT:k="" WRITE copy(k),! } ```
