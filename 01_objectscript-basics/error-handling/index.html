    %Status & Error Handling¶

    Exam Domain: T4 · Code — error handling với %Status, TRY/CATCH là yêu cầu bắt buộc

    Overview¶

    Hầu hết mọi method trong IRIS trả về %Status — không kiểm tra là bỏ sót lỗi thầm lặng.

    ; ❌ Sai — không kiểm tra lỗi
DO person.%Save()

; ✅ Đúng
SET sc = person.%Save()
IF $$$ISERR(sc) { DO $SYSTEM.Status.DisplayError(sc) }

    What is %Status?¶

    %Status là một string đặc biệt: - 1 = thành công - String mã hóa lỗi = thất bại

    Core Macros¶

    Cách chuẩn để kiểm tra %Status:

    ; Tạo status OK
SET sc = $$$OK              ; = 1

; Kiểm tra thành công
IF sc = $$$OK { ... }
IF $$$ISOK(sc) { ... }      ; tương đương

; Kiểm tra lỗi
IF $$$ISERR(sc) { ... }

; Ví dụ thực tế
SET sc = ##class(MyApp.Person).%Save()
IF $$$ISERR(sc) {
    WRITE "Lỗi: ", $SYSTEM.Status.GetErrorText(sc), !
    QUIT sc
}

    Creating Error Status¶

    ; Tạo error từ text
SET sc = $$$ERROR($$$GeneralError, "Tên không được để trống")

; Các error codes thường dùng
$$$GeneralError          ; lỗi chung
$$$InvalidArgument       ; đối số không hợp lệ
$$$AccessDenied          ; không có quyền

; Wrap error với context
SET sc = $$$ERROR($$$GeneralError, "Save failed for ID: " _ id)

    TRY / CATCH¶

    TRY {
    SET result = ..RiskyOperation()
    IF $$$ISERR(result) { $$$ThrowStatus(result) }
    WRITE "Success: ", result, !
}
CATCH ex {
    WRITE "Exception: ", ex.DisplayString(), !
    WRITE "Type: ", ex.%ClassName(), !
}

    Exception Object Properties¶

    ex.Name          ; tên exception
ex.Code          ; error code
ex.Data          ; data kèm theo
ex.Location      ; nơi xảy ra (method, line)
ex.DisplayString() ; string mô tả đầy đủ
ex.AsStatus()    ; convert thành %Status

    $$$ThrowOnError Pattern¶

    ; Thay vì viết IF $$$ISERR(sc) { THROW ... }
; Dùng macro này cho gọn:
$$$ThrowOnError(sc)

; Ví dụ:
TRY {
    SET sc = person.%Save()
    $$$ThrowOnError(sc)

    SET sc = ##class(Validator).Validate(person)
    $$$ThrowOnError(sc)

    WRITE "All OK!", !
}
CATCH ex {
    WRITE "Failed: ", ex.DisplayString(), !
}

    Returning Errors from Methods¶

    Method SavePerson(pName As %String) As %Status
{
    ; Validate
    IF pName = "" {
        RETURN $$$ERROR($$$GeneralError, "Name is required")
    }

    SET person = ##class(MyApp.Person).%New()
    SET person.Name = pName

    ; Trả về status của %Save trực tiếp
    RETURN person.%Save()
}

; Gọi method:
SET sc = ..SavePerson("Alice")
IF $$$ISERR(sc) {
    DO $SYSTEM.Status.DisplayError(sc)
}

    $SYSTEM.Status Utilities¶

    ; In lỗi ra terminal
DO $SYSTEM.Status.DisplayError(sc)

; Lấy error text
SET msg = $SYSTEM.Status.GetErrorText(sc)

; Lấy error code
SET code = $SYSTEM.Status.GetErrorCodes(sc)

; Kết hợp nhiều status
SET sc1 = method1()
SET sc2 = method2()
SET combined = $SYSTEM.Status.AppendStatus(sc1, sc2)

    Key Points¶

    • ✅ Luôn gán return value của method vào biến sc
    • ✅ Luôn kiểm tra $$$ISERR(sc) sau các operation quan trọng
    • ✅ Dùng TRY/CATCH khi gọi code có thể throw exception
    • ✅ Method nên RETURN %Status, không phải void
    • 💡 Dùng $$$ThrowOnError(sc) trong TRY block để code gọn hơn
    • ⚠️ DO person.%Save() không kiểm tra lỗi — lỗi thầm lặng!

    🖥️ Terminal Snippets¶

    ; Test %Status
SET sc = $$$OK
WRITE "$$$ISOK: ", $$$ISOK(sc), !       ; 1
WRITE "$$$ISERR: ", $$$ISERR(sc), !     ; 0

; Tạo error và đọc message
SET sc = $$$ERROR($$$GeneralError, "Test error message")
WRITE $SYSTEM.Status.GetErrorText(sc), !

; TRY/CATCH đơn giản
TRY {
    THROW ##class(%Exception.General).%New("Test","0","","Test exception")
} CATCH ex {
    WRITE "Caught: ", ex.DisplayString(), !
}
