    01 — ObjectScript Basics¶

    📌 Key Concepts¶

    Biến (Variables)¶

    ; Local variable (chỉ tồn tại trong method/routine hiện tại)
SET x = 10
SET name = "Alice"

; Global variable (lưu trữ persistent trên disk)
SET ^GlobalVar = "value"

    Các Kiểu Dữ Liệu¶

    Loại Mô tả Ví dụ
    String Chuỗi ký tự "Hello"
    Numeric Số (int/float) 42, 3.14
    List $LISTBUILD $LB("a","b","c")
    Multidimensional Array Subscripted local arr(1,2) = "val"

    Control Flow¶

    ; IF / ELSEIF / ELSE
IF x > 10 {
    WRITE "Lớn hơn 10"
} ELSEIF x = 10 {
    WRITE "Bằng 10"
} ELSE {
    WRITE "Nhỏ hơn 10"
}

; FOR loop (start:step:end)
FOR i = 1:1:10 {
    WRITE i, !
}

; WHILE loop
WHILE x > 0 {
    SET x = x - 1
}

; DO WHILE
DO {
    SET x = x + 1
} WHILE x < 10

    Built-in Functions Hay Dùng¶

    ; --- String ---
$LENGTH(str)              ; độ dài chuỗi
$EXTRACT(str, from, to)   ; cắt substring
$FIND(str, target)        ; tìm vị trí (trả về pos sau target)
$REPLACE(str, old, new)   ; thay thế
$PIECE(str, delim, n)     ; lấy phần tử thứ n phân cách bởi delim
$UPPERCASE(str)           ; chuyển hoa
$LOWERCASE(str)           ; chuyển thường

; --- Numeric ---
$RANDOM(n)                ; số ngẫu nhiên 0 đến n-1
$TRUNCATE(num, dec)       ; cắt số thập phân

; --- Date/Time ---
$HOROLOG                  ; định dạng nội bộ "days,seconds"
$NOW()                    ; timestamp hiện tại
$ZDATETIME($HOROLOG, 3)   ; YYYY-MM-DD HH:MM:SS

    Câu Lệnh Thường Dùng¶

    SET x = 5             ; gán
WRITE x, !            ; in + newline
KILL x                ; xóa biến
QUIT value            ; return giá trị từ method

    ❓ Những Điểm Cần Nhớ¶

    • ObjectScript không phân biệt hoa/thường với commands (write = WRITE)
    • Dấu ! trong WRITE = xuống dòng
    • Dấu ; bắt đầu comment
    • Variables không cần khai báo kiểu trước

    🖥️ Terminal Snippets¶

    Các lệnh copy-paste thẳng vào IRIS Terminal để thử nhanh:

    ; --- Biến & In ---
SET name = "Alice"  SET age = 30
WRITE "Hello, ", name, "! Age: ", age, !

; --- String functions ---
SET s = "Hello InterSystems IRIS"
WRITE $LENGTH(s), !
WRITE $UPPERCASE(s), !
WRITE $PIECE(s, " ", 2), !          ; lấy từ thứ 2: "InterSystems"
WRITE $EXTRACT(s, 1, 5), !          ; "Hello"
WRITE $REPLACE(s, "Hello", "Hi"), !

; --- FOR loop ---
FOR i = 1:1:5 { WRITE i, " " }
WRITE !

; --- FizzBuzz (1 dòng) ---
FOR i=1:1:20 { IF i#15=0 { WRITE "FizzBuzz" } ELSEIF i#3=0 { WRITE "Fizz" } ELSEIF i#5=0 { WRITE "Buzz" } ELSE { WRITE i } WRITE ! }

; --- IF/ELSE ---
SET score = 85
IF score >= 90 { WRITE "A" } ELSEIF score >= 80 { WRITE "B" } ELSEIF score >= 70 { WRITE "C" } ELSE { WRITE "F" }
WRITE !

; --- Date/Time ---
WRITE $ZDATETIME($HOROLOG, 3), !
