    00 — Tổng Quan InterSystems IRIS¶

    IRIS Là Gì?¶

    InterSystems IRIS Data Platform là một nền tảng dữ liệu hợp nhất (unified data platform) — kết hợp trong một sản phẩm duy nhất:

    Thành Phần Mô Tả
    Database Multi-model: object, relational (SQL), document, key-value
    Application Server Chạy ObjectScript, Python, Java, .NET trực tiếp trong engine
    Interoperability Engine Tích hợp hệ thống, message routing, transformation
    Analytics Adaptive Analytics, BI (DeepSee/IntegratedML)

    💡 Khác với hầu hết hệ thống khác, trong IRIS code và data sống cùng một engine — không có tầng middleware riêng biệt.

    Các Khái Niệm Nền Tảng¶

    1. Globals — Trái Tim Của IRIS¶

    Mọi thứ trong IRIS đều được lưu bằng Globals — cấu trúc dữ liệu đa chiều, sparse, persistent: 

    ^Data("users", 1, "name") = "Alice"
^Data("users", 1, "age")  = 30
    - Class %Persistent → IRIS tự sinh ra globals phía sau - SQL tables → cũng là globals - Rất nhanh, không cần schema cứng nhắc

    2. Namespace & Database¶

    Namespace  =  logical view  (USER, MYAPP, %SYS...)
Database   =  physical file (.DAT) chứa globals & code
    - Một namespace map đến một hoặc nhiều databases - Code (classes) và data có thể ở databases khác nhau

    3. Multi-Model Access — Cùng Một Data¶

    ; Cách 1: Object
SET p = ##class(MyApp.Person).%OpenId(1)
WRITE p.Name

; Cách 2: SQL
&sql(SELECT Name FROM MyApp.Person WHERE ID = 1)

; Cách 3: Global trực tiếp
WRITE ^MyApp.PersonD(1, "Name")
    Ba cách truy cập cùng một dữ liệu — không cần sync.

    4. ObjectScript¶

    Ngôn ngữ lập trình native của IRIS: - Interpreted & compiled (bytecode) - Strongly integrated với database engine - Hỗ trợ OOP đầy đủ (class, inheritance, polymorphism) - Ngoài ra IRIS còn hỗ trợ: Python, Java, .NET, Node.js

    Các Thành Phần Chính Cần Biết¶

    Management Portal¶

    Web UI tại http://localhost:52773/csp/sys/UtilHome.csp - Quản lý namespaces, databases - SQL Explorer (chạy SQL query) - System Explorer (xem classes, globals) - Interoperability (quản lý Productions) - Security (users, roles)

    IRIS Terminal¶

    Shell tương tác để chạy ObjectScript: 

    docker exec -it iris-dev iris session iris
    Hoặc qua Management Portal → System > Terminal

    VS Code + ObjectScript Extension¶

    • Edit & compile .cls files trực tiếp
    • Xem/sửa globals, classes trên server
    • Debug ObjectScript
