    Quiz 01 — SQL in IRIS¶

    Topic: SQL in IRIS (Dynamic SQL, Embedded SQL, Class Query, SQLCODE, SQL Injection)
    Questions: 12
    Difficulty: Beginner → Intermediate
    Exam Domain(s): T3.1 (Dynamic SQL), T3.2 (Embedded SQL), T3.3 (Class Query)

    📋 Exam format reminder: The real exam has 65 questions (2.5h, 65% to pass). Question types: Multiple Choice (one answer) and Multiple Response (select all that apply). InterSystems Documentation is available during the exam — but there's no time to look up everything.

    Questions¶

    Q1. (Multiple Choice) A persistent class MyApp.Order is defined in IRIS. What is the corresponding SQL table name?

    • A) MyApp.Order
    • B) MyApp_Order
    • C) Order
    • D) MyApp::Order

    Q2. (Multiple Choice) Which Dynamic SQL method prepares and executes a query in a single step without calling %Prepare first?

    • A) stmt.%Execute()
    • B) %SQL.Statement.%RunQuery()
    • C) ##class(%SQL.Statement).%ExecDirect()
    • D) stmt.%Query()

    Q3. (Multiple Choice) What does the following Dynamic SQL code print if a person with Age > 25 exists?

    SET stmt = ##class(%SQL.Statement).%New()
DO stmt.%Prepare("SELECT Name FROM MyApp.Person WHERE Age > ?")
SET rs = stmt.%Execute(25)
WHILE rs.%Next() {
    WRITE rs.%Get("Name"), !
}
    • A) Nothing — %Get requires a column index, not a name
    • B) The name of each person with Age > 25, one per line
    • C) Error — ? is not valid in Dynamic SQL; use :var instead
    • D) The number of rows returned

    Q4. (Multiple Choice) After running &sql(SELECT Name INTO :name FROM MyApp.Person WHERE %ID = :id), which variable tells you whether the query succeeded?

    • A) %SQLCODE
    • B) SQLCODE
    • C) sc
    • D) rs.%SQLCODE

    Q5. (Multiple Choice) What does SQLCODE = 100 mean after an Embedded SQL statement?

    • A) 100 rows were affected
    • B) The query executed successfully with data returned
    • C) No data was found (end of cursor or no matching row)
    • D) A fatal SQL error occurred

    Q6. (Multiple Response — select all that apply) Which of the following are correct ways to avoid SQL injection in IRIS Dynamic SQL?

    • A) Use ? placeholders and pass values to %Execute()
    • B) Use %SQL.Statement.%Prepare() with parameterized queries
    • C) Concatenate user input directly into the query string after calling $ZCONVERT
    • D) Use Embedded SQL with :variable host variables

    Q7. (Multiple Choice) What is the correct order of operations when using a cursor in Embedded SQL?

    • A) DECLARE → FETCH → OPEN → CLOSE
    • B) OPEN → DECLARE → FETCH → CLOSE
    • C) DECLARE → OPEN → FETCH (loop until SQLCODE ≠ 0) → CLOSE
    • D) OPEN → FETCH → CLOSE (no DECLARE needed)

    Q8. (Multiple Choice) A Class Query named FindByAge is defined in MyApp.Person. How do you call it from ObjectScript?

    • A) ##class(MyApp.Person).FindByAge(25)
    • B) ##class(MyApp.Person).FindByAgeFunc(25)
    • C) ##class(%SQL.Statement).%ExecDirect(, "FindByAge", 25)
    • D) DO ##class(MyApp.Person).FindByAge.Execute(25)

    Q9. (Multiple Choice) What does the following code print if no person with ID 99 exists?

    SET id = 99
&sql(SELECT Name INTO :name FROM MyApp.Person WHERE %ID = :id)
IF SQLCODE = 0 {
    WRITE name, !
} ELSEIF SQLCODE = 100 {
    WRITE "Not found", !
} ELSE {
    WRITE "Error: ", %msg, !
}
    • A) Nothing
    • B) Not found
    • C) Error: ...
    • D) 99

    Q10. (Multiple Choice) After a successful INSERT using Dynamic SQL, which result set property gives you the ID of the newly inserted row?

    • A) rs.%ROWID
    • B) rs.%ID
    • C) rs.%LastInsertID
    • D) rs.%Get("%ID")

    Q11. (Multiple Response — select all that apply) Which of the following are true about Embedded SQL compared to Dynamic SQL?

    • A) Embedded SQL is checked for syntax errors at compile time
    • B) Embedded SQL uses :variable host variables; Dynamic SQL uses ? placeholders
    • C) Embedded SQL is generally faster because it is pre-compiled
    • D) Embedded SQL can accept a fully dynamic table name at runtime
    • E) Both Embedded SQL and Dynamic SQL set the SQLCODE variable after execution

    Q12. (Multiple Choice) Which SQLCODE value indicates a unique constraint violation (duplicate key)?

    • A) -1
    • B) -119
    • C) 100
    • D) -400

     

     

     

     

     

    ✅ Answers¶

    # Type Answer Exam Domain Explanation
    Q1 MC B T3.1 IRIS maps class package dots to underscores in SQL. MyApp.Order → SQL table MyApp_Order.
    Q2 MC C T3.1 ##class(%SQL.Statement).%ExecDirect(, sqlString, args...) prepares and executes in one call. Useful for one-off queries where you don't need to reuse the prepared statement.
    Q3 MC B T3.1 ? is the correct placeholder for Dynamic SQL in IRIS. rs.%Get("ColumnName") retrieves by name. The loop prints each matching person's name.
    Q4 MC B T3.2 After every &sql(...) statement, IRIS automatically sets the SQLCODE variable (no % prefix) in the current scope. %msg holds the error text when SQLCODE < 0.
    Q5 MC C T3.2 SQLCODE = 100 is the "no data" code — the query ran successfully but found no matching rows, or the cursor has reached the end of the result set.
    Q6 MR A, B, D T3.1 Using ? with %Execute, using %Prepare with parameters, and using Embedded SQL :variables all prevent SQL injection. Directly concatenating user input — even after $ZCONVERT — is never safe.
    Q7 MC C T3.2 The correct cursor lifecycle is: DECLARE (define the cursor) → OPEN (execute) → FETCH in a loop until SQLCODE ≠ 0 → CLOSE.
    Q8 MC B T3.3 IRIS auto-generates a method named <QueryName>Func() for each Class Query. For FindByAge, the generated method is FindByAgeFunc(pMinAge).
    Q9 MC B T3.2 When no row matches, Embedded SQL sets SQLCODE = 100 (no data found). The ELSEIF SQLCODE = 100 branch fires and prints "Not found".
    Q10 MC A T3.1 After a Dynamic SQL INSERT, rs.%ROWID contains the %ID of the newly inserted row. rs.%ROWCOUNT holds the number of affected rows.
    Q11 MR A, B, C T3.2 A: Embedded SQL syntax is validated at compile time. B: Correct — :var vs ?. C: Embedded SQL is pre-compiled and faster for fixed queries. D: Wrong — Embedded SQL cannot use dynamic table names at runtime (that requires Dynamic SQL). E: False — the local SQLCODE variable is only set automatically by Embedded SQL. In Dynamic SQL you check rs.%SQLCODE on the result set object; the local SQLCODE variable is not set.
    Q12 MC B T3.1 SQLCODE = -119 indicates a unique constraint violation (duplicate key). SQLCODE = 100 is no data. Any negative SQLCODE is an error; -119 specifically means uniqueness was violated.

    MC = Multiple Choice (one answer) · MR = Multiple Response (select all that apply)
