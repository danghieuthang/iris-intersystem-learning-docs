    Indices¶

    Exam Domain: T1 · Architecture — T1.2.2: xác định và thêm index phù hợp để cải thiện hiệu năng query

    Why Indices Matter¶

    Nếu không có index, mọi SQL query đều phải quét toàn bộ bảng (full table scan) qua global. Với index đúng, IRIS nhảy thẳng đến các row khớp.

    -- Không có index trên Age: quét TẤT CẢ row
SELECT Name FROM MyApp.Person WHERE Age > 25

-- Có index trên Age: tra cứu O(log n)
Index AgeIdx On Age;

    Standard Index¶

    Index đa năng. Lưu danh sách giá trị → ID theo thứ tự sắp xếp.

    /// Index đơn field
Index NameIdx On Name;

/// Composite — hữu ích khi query lọc trên nhiều column cùng lúc
Index NameAgeIdx On (Name, Age);

    Khi nào dùng: Bất kỳ column nào bạn filter/sort thường xuyên trong SQL.

    Unique Index¶

    Tương tự Standard nhưng còn đảm bảo tính duy nhất — %Save() thất bại nếu bị trùng.

    Index EmailIdx On Email [ Unique ];

    ; %Save() trả về lỗi nếu Email đã tồn tại
SET sc = person.%Save()
IF $$$ISERR(sc) {
    ; SQLCODE -119 = vi phạm unique constraint
}

    Bitmap Index¶

    Tối ưu cho các field low-cardinality (ít giá trị phân biệt: boolean, status, gender...).

    Index StatusIdx On Status [ Type = bitmap ];
Index IsActiveIdx On IsActive [ Type = bitmap ];

    Cách hoạt động: Lưu 1 bit cho mỗi row — rất nhanh cho COUNT(*), range query, và kết hợp điều kiện AND/OR.

    Khi nào dùng: Field có < ~100 giá trị phân biệt, dùng trong aggregate query.
    Không nên dùng: Field high-cardinality như Name, Email, ID.

    Bitslice Index¶

    Tối ưu cho range query và SUM/AVG trên field số.

    Index AgeIdx On Age [ Type = bitslice ];

    -- Rất nhanh khi có bitslice index:
SELECT AVG(Age), MAX(Age) FROM MyApp.Person WHERE Age BETWEEN 20 AND 40

    IDKEY Index¶

    Biến một property (hoặc tổ hợp) thành primary key của object thay vì ID tự sinh.

    Index PatientIdx On PatientCode [ Type = key ];

    ⚠️ Một khi đã set, không thể thay đổi sau khi đã có dữ liệu. Dùng cẩn thận.

    Expression Index¶

    Index trên giá trị đã biến đổi — hữu ích cho tìm kiếm không phân biệt hoa thường.

    /// Index trên chữ hoa của Name để tìm kiếm case-insensitive
Index NameUpper On (Name As %SQLUPPER);

    -- Dùng index NameUpper dù query dùng Name gốc
SELECT * FROM MyApp.Person WHERE %SQLUPPER(Name) = 'ALICE'

    Choosing the Right Index¶

    Tình huống Loại Index
    Filter/sort trên bất kỳ column Standard
    Đảm bảo tính duy nhất (email, code) Unique
    Field low-cardinality (status, boolean) Bitmap
    Aggregate trên số (SUM, AVG, range) Bitslice
    Primary key tùy chỉnh Key (IDKEY)
    Tìm văn bản không phân biệt hoa thường Standard với %SQLUPPER

    Query Plan Analysis¶

    Trong Management Portal → SQL Explorer, chạy EXPLAIN để xem index có được dùng không:

    EXPLAIN SELECT Name FROM MyApp.Person WHERE Age > 25

    Tìm "index scan" thay vì "table scan" trong plan. Table scan trên bảng lớn = đang thiếu index.

    Index Maintenance¶

    ; Rebuild TẤT CẢ index của một class (sau khi import hàng loạt)
DO ##class(MyApp.Person).%BuildIndices()

; Rebuild một index cụ thể
DO ##class(MyApp.Person).%BuildIndices($LISTBUILD("NameIdx"))

; Purge (xóa) và rebuild lại
DO ##class(MyApp.Person).%PurgeIndices()
DO ##class(MyApp.Person).%BuildIndices()

    Key Points¶

    • ✅ Unique index tự sinh method <IndexName>Open(value) để lookup theo giá trị đó
    • ✅ Bitmap index chỉ hiệu quả với low-cardinality fields (< ~100 giá trị phân biệt)
    • ✅ Bitslice index tối ưu cho SUM, AVG, MAX, và range query trên số
    • ⚠️ Sau khi import dữ liệu hàng loạt: phải chạy %BuildIndices() để rebuild
    • ⚠️ IDKEY/Key index không thể thay đổi sau khi đã có data
    • 💡 Chạy EXPLAIN SELECT... trong SQL Explorer để xác nhận index được sử dụng

    🖥️ Terminal Snippets¶

    ; Kiểm tra các index hiện có trên một class
SET classDef = ##class(%Dictionary.ClassDefinition).%OpenId("MyApp.Person")
FOR i=1:1:classDef.Indices.Count() {
    SET idx = classDef.Indices.GetAt(i)
    WRITE idx.Name, " on ", idx.Properties, " [", idx.Type, "]", !
}

; Rebuild index sau khi load dữ liệu hàng loạt
DO ##class(MyApp.Person).%BuildIndices()
WRITE "Done", !
