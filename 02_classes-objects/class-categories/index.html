    Class Categories¶

    Exam Domain: T1 · Architecture — T1.2.1: phân biệt Persistent, Registered, Serial và Abstract class

    Overview¶

    Loại Superclass Lưu trữ? Độc lập? Dùng khi
    Persistent %Persistent ✅ Database ✅ Có Dữ liệu cần tồn tại sau khi process kết thúc
    Registered %Registered ❌ Memory ✅ Có Object tạm thời, helper, service
    Serial %Serial ✅ (trong parent) ❌ Không — chỉ nhúng Nhóm fields liên quan lưu bên trong object khác
    Abstract (không lưu) ❌ ❌ Định nghĩa interface/hành vi chung — không khởi tạo trực tiếp
    Datatype %DataType N/A ❌ Kiểu dữ liệu scalar tùy chỉnh (vd: email, phone)

    %Persistent¶

    Lưu xuống database IRIS dưới dạng global. Có Object ID (%ID) riêng.

    Class MyApp.Person Extends %Persistent
{
    Property Name As %String;
    Property Age  As %Integer;
}

; Các thao tác CRUD:
SET p = ##class(MyApp.Person).%New()
SET p.Name = "Alice"  DO p.%Save()

SET p = ##class(MyApp.Person).%OpenId(1)    ; mở theo ID
DO ##class(MyApp.Person).%DeleteId(1)        ; xóa theo ID
DO ##class(MyApp.Person).%KillExtent()       ; xóa TẤT CẢ (cẩn thận!)

    Các method kế thừa từ %Persistent:

    Method Mô tả
    %New() Tạo instance mới (trong memory)
    %Save() Lưu xuống database → trả về %Status
    %OpenId(id) Mở object theo ID
    %DeleteId(id) Xóa theo ID → trả về %Status
    %KillExtent() Xóa toàn bộ instances
    %Id() Lấy ID của object (sau khi save)
    %IsModified() Kiểm tra có thay đổi chưa lưu không
    %Rollback() Hủy bỏ thay đổi trong memory

    %Registered¶

    Chỉ tồn tại trong memory — không bao giờ được ghi xuống disk.

    Class MyApp.Validator Extends %Registered
{
    Property Rules As List Of %String;

    Method Validate(pValue As %String) As %Boolean
    {
        ; logic kiểm tra
        RETURN 1
    }
}

; Dùng — không cần và không có %Save()
SET v = ##class(MyApp.Validator).%New()
DO v.Rules.Insert("notEmpty")
WRITE v.Validate("test")

    💡 Dùng cho: service object, validator, DTO, bất cứ thứ gì không cần lưu trữ.

    %SerialObject¶

    Lưu nhúng bên trong một persistent object — không có ID riêng.

    Class MyApp.Address Extends %SerialObject
{
    Property Street As %String;
    Property City   As %String;
    Property Zip    As %String(MAXLEN=10);
}

Class MyApp.Person Extends %Persistent
{
    Property Name    As %String;
    Property Address As MyApp.Address;   ; nhúng vào đây
}

; Cách dùng
SET p = ##class(MyApp.Person).%New()
SET p.Name = "Alice"
SET p.Address.Street = "123 Lê Lợi"
SET p.Address.City   = "Hà Nội"
DO p.%Save()   ; Address được lưu cùng Person — không cần %Save() riêng

    Cách lưu trữ trong global:
    Tất cả fields của Address được serialize và lưu trong cùng row với Person — không tạo bảng riêng.

    ⚠️ %SerialObject không thể mở bằng ID (vì không có). Chỉ truy cập qua parent.

    Abstract Class¶

    Định nghĩa interface/hành vi chung. Không thể khởi tạo trực tiếp.

    Class MyApp.Animal Extends %Persistent [ Abstract ]
{
    Property Name As %String;

    /// Subclass bắt buộc phải implement
    Method Speak() As %String [ Abstract ]
    {
    }
}

Class MyApp.Dog Extends MyApp.Animal
{
    Method Speak() As %String
    {
        RETURN "Woof!"
    }
}

    Common Mixins¶

    Mixin Thêm khả năng
    %JSON.Adaptor %JSONExport(), %JSONImport() — serialization JSON
    %XML.Adaptor Serialization XML
    %Populate Populate() — tạo dữ liệu test ngẫu nhiên 
    ; Kế thừa nhiều class — kết hợp tùy ý
Class MyApp.Person Extends (%Persistent, %JSON.Adaptor, %Populate)

    Decision Tree¶

    Dữ liệu có cần tồn tại sau khi process kết thúc không?
├── KHÔNG → %Registered (chỉ trong memory)
└── CÓ   → Object có cần ID riêng không?
            ├── KHÔNG → %SerialObject (nhúng vào parent)
            └── CÓ   → %Persistent
                        └── Class có được khởi tạo trực tiếp không?
                            ├── KHÔNG → Thêm keyword [ Abstract ]
                            └── CÓ   → %Persistent thông thường

    Key Points¶

    • ✅ %Persistent có %ID riêng, lưu xuống database với %Save()
    • ✅ %SerialObject lưu inline trong parent — không cần và không có %Save() riêng
    • ✅ %Registered chỉ trong memory — dùng cho validator, DTO, helper object
    • ⚠️ Abstract class không thể %New() — chỉ dùng để subclass
    • ⚠️ %SerialObject không có ID — không thể truy xuất độc lập
    • 💡 %JSON.Adaptor là mixin phổ biến nhất — thêm tự do vào bất kỳ class nào

    🖥️ Terminal Snippets¶

    ; Kiểm tra class có phải là Persistent không
WRITE $CLASSMETHOD("MyApp.Person", "%IsA", "%Persistent"), !  ; 1 = có

; Mở object và kiểm tra có thay đổi chưa lưu không
SET p = ##class(MyApp.Person).%OpenId(1)
SET p.Name = "Tên Mới"
WRITE p.%IsModified(), !   ; 1

; Hủy thay đổi trong memory
DO p.%Rollback()
WRITE p.%IsModified(), !   ; 0
