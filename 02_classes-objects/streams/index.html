    Stream¶

    Exam domain: T1.2.4 — Xác định khi nào stream là kiểu dữ liệu phù hợp

    Stream vs String¶

    %String Stream
    Kích thước tối đa 3,641,144 ký tự Không giới hạn
    Lưu trữ Inline trong global của object Global stream riêng biệt
    Hiệu năng Nhanh cho giá trị nhỏ Hiệu quả cho nội dung lớn
    Dùng trong SQL Column thông thường Kiểu %Stream.GlobalCharacter

    💡 Quy tắc thực tế: Nếu nội dung có thể vượt ~1MB, hoặc không giới hạn kích thước (upload file, HTML, XML, JSON blob lớn) → dùng Stream.

    Các Stream Class¶

    Class Dùng cho
    %Stream.GlobalCharacter Dữ liệu văn bản (lưu trong global)
    %Stream.GlobalBinary Dữ liệu nhị phân — ảnh, PDF, file
    %Stream.FileCharacter Văn bản lưu trên filesystem
    %Stream.FileBinary Nhị phân lưu trên filesystem

    Phổ biến nhất trong thực tế: %Stream.GlobalCharacter cho văn bản, %Stream.GlobalBinary cho nhị phân.

    Khai Báo Stream Property¶

    Class MyApp.Document Extends %Persistent
{
    Property Title   As %String(MAXLEN = 200);
    Property Content As %Stream.GlobalCharacter;   ; văn bản không giới hạn
    Property File    As %Stream.GlobalBinary;      ; file đính kèm nhị phân
}

    Ghi Vào Stream¶

    SET doc = ##class(MyApp.Document).%New()
SET doc.Title = "Báo Cáo Tháng 6"

; Ghi từng phần
DO doc.Content.Write("Phần nội dung đầu tiên. ")
DO doc.Content.Write("Phần nội dung tiếp theo.")

; Hoặc ghi toàn bộ một lần
DO doc.Content.Write("Toàn bộ nội dung trong một lần gọi.")

DO doc.%Save()

    Đọc Từ Stream¶

    SET doc = ##class(MyApp.Document).%OpenId(1)

; Đọc toàn bộ stream một lần
WRITE doc.Content.Read(), !

; Đọc theo từng chunk (cho nội dung rất lớn)
DO doc.Content.Rewind()
WHILE 'doc.Content.AtEnd {
    SET chunk = doc.Content.Read(32000)   ; đọc tối đa 32KB mỗi lần
    ; xử lý chunk
}

    Sao Chép Giữa Các Stream¶

    ; Sao chép một stream vào stream khác
SET sc = dest.CopyFrom(source)

; Sao chép từ string vào stream
DO myStream.Write(myString)

; Sao chép từ stream sang string (chỉ an toàn nếu nội dung < giới hạn string)
SET str = myStream.Read()

    Stream Trong REST / HTTP¶

    ; Đọc request body dạng stream trong REST endpoint
SET requestBody = %request.Content   ; đây đã là một stream

DO requestBody.Rewind()
SET jsonStr = requestBody.Read()
SET body = {}.%FromJSON(jsonStr)

; Ghi response lớn
DO %response.Output.Write(largeContent)

    Kiểm Tra Kích Thước Stream¶

    ; Kích thước tính bằng byte (không luôn chính xác trước khi save)
WRITE doc.Content.Size, !

; Kiểm tra có rỗng không
WRITE doc.Content.IsEmpty(), !

    🖥️ Terminal Snippets¶

    ; Tạo và ghi vào stream
SET s = ##class(%Stream.GlobalCharacter).%New()
DO s.Write("Xin ")
DO s.Write("chào!")
WRITE s.Read(), !           ; Xin chào!

; Rewind và đọc lại
DO s.Rewind()
WRITE s.Read(4), !          ; Xin 

; Kiểm tra kích thước
WRITE s.Size, !             ; 9
