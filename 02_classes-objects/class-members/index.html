    Các Thành Phần Trong Class (Class Members)¶

    Tất cả các thành phần có thể khai báo bên trong một IRIS class.

    1. Property (Thuộc Tính)¶

    Đại diện cho các field dữ liệu của class.

    ; Kiểu cơ bản
Property Name      As %String(MAXLEN = 100) [ Required ];
Property Age       As %Integer;
Property Score     As %Numeric(SCALE = 2);
Property IsActive  As %Boolean [ InitialExpression = 1 ];
Property CreatedAt As %TimeStamp;

; Collection
Property Tags      As List Of %String;
Property Scores    As Array Of %Integer;

; Object reference — Serial nhúng vào
Property Address   As MyApp.Address;

; Object reference — liên kết Persistent (lưu dưới dạng foreign key)
Property Manager   As MyApp.Employee;

    Keyword của Property (bên trong [ ])¶

    Keyword Tác dụng
    Required Không được để trống — %Save() thất bại nếu chưa set
    InitialExpression Giá trị mặc định khi gọi %New()
    Calculated Không lưu trữ — giá trị được tính qua method Get/Set
    Transient Không lưu trữ — chỉ trong memory, không persist
    ReadOnly Chỉ đọc từ bên ngoài class
    Private Không truy cập được từ bên ngoài class
    Internal Ẩn khỏi tài liệu class

    Tham Số của Property (bên trong ( ))¶

    Tham số Áp dụng cho Tác dụng
    MAXLEN %String Độ dài tối đa (mặc định 50, dùng 0 để không giới hạn)
    SCALE %Numeric Số chữ số thập phân
    MINVAL, MAXVAL %Integer, %Numeric Kiểm tra khoảng giá trị
    VALUELIST %String Danh sách giá trị hợp lệ phân cách bằng dấu phẩy
    PATTERN %String Kiểm tra theo pattern (tương tự regex)
    JSONNAME Bất kỳ Đổi tên field khi serialize ra JSON 
    Property Status As %String(VALUELIST = ",active,inactive,pending") [ Required ];
Property Email  As %String(MAXLEN = 200, PATTERN = ".+@.+\..+");

    Collection Property¶

    Property Tags As List Of %String;

; Cách dùng
SET obj = ##class(MyApp.Person).%New()
DO obj.Tags.Insert("developer")
DO obj.Tags.Insert("iris")
WRITE obj.Tags.Count(), !        ; 2
WRITE obj.Tags.GetAt(1), !       ; developer
DO obj.Tags.RemoveAt(1)

    Property Config As Array Of %String;

; Cách dùng
SET obj.Config.SetAt("value1", "key1")
WRITE obj.Config.GetAt("key1"), !

    2. Method (Phương Thức)¶

    ; Instance method — gọi trên một instance cụ thể
Method Greet(pPrefix As %String = "Hello") As %String
{
    RETURN pPrefix _ ", " _ ..Name _ "!"
}

; ClassMethod — gọi trên class (không cần instance)
ClassMethod Create(pName As %String, pAge As %Integer) As MyApp.Person
{
    SET obj = ##class(MyApp.Person).%New()
    SET obj.Name = pName
    SET obj.Age  = pAge
    RETURN obj
}

    Method vs ClassMethod¶

    Method ClassMethod
    Gọi trên Instance: obj.Greet() Class: ##class(X).Create()
    Dùng .. (self) được ✅ ❌
    Thường dùng cho Logic xử lý trên object Factory, tiện ích, query

    Callback Method (Lifecycle Hook)¶

    Override để can thiệp vào vòng đời của object:

    ; Gọi bởi %New() — constructor
Method %OnNew(pArg As %String) As %Status
{
    SET ..CreatedAt = $NOW()
    RETURN $$$OK
}

; Gọi trước %Save() — trả về lỗi để ngăn lưu
Method %OnBeforeSave(insert As %Boolean) As %Status
{
    IF ..Name = "" { RETURN $$$ERROR($$$GeneralError, "Name bắt buộc phải có") }
    RETURN $$$OK
}

; Gọi sau %Save()
Method %OnAfterSave(insert As %Boolean) As %Status
{
    RETURN $$$OK
}

; Gọi trước %DeleteId()
ClassMethod %OnDelete(oid As %ObjectIdentity) As %Status
{
    RETURN $$$OK
}

    3. Parameter (Hằng Số Class)¶

    Hằng số được khai báo ở cấp class — cố định lúc compile, không thay đổi theo instance.

    Class MyApp.Config Extends %Registered
{
    Parameter VERSION = "1.0.0";
    Parameter MAX_RETRY As %Integer = 3;
    Parameter TIMEOUT As %Integer = 30;
}

; Truy cập từ bên trong class:
WRITE ..#VERSION, !

; Truy cập từ bên ngoài:
WRITE ##class(MyApp.Config).#VERSION, !
WRITE $PARAMETER("MyApp.Config", "VERSION"), !

    💡 Parameter hay được dùng trong subclass của %CSP.REST để cấu hình:
    Parameter CONTENTTYPE = "application/json";

    4. Index (Chỉ Mục)¶

    Hướng dẫn IRIS xây dựng cấu trúc tra cứu cho SQL query. Xem indices.md để biết chi tiết.

    ; Index cơ bản trên Name
Index NameIdx On Name;

; Unique index — đảm bảo tính duy nhất
Index EmailIdx On Email [ Unique ];

; Index composite
Index NameAgeIdx On (Name, Age);

; Bitmap index — dùng cho field có ít giá trị phân biệt (boolean, status...)
Index StatusIdx On Status [ Type = bitmap ];

    5. XData Block¶

    Dữ liệu XML/JSON nhúng trực tiếp vào class — dùng cho cấu hình, URL map, v.v.

    XData UrlMap [ XMLNamespace = "http://www.intersystems.com/urlmap" ]
{
<Routes>
  <Route Url="/people" Method="GET" Call="GetAll"/>
</Routes>
}

    6. Query (Truy Vấn Đặt Tên)¶

    SQL query được đặt tên và định nghĩa ngay trong class — gọi được qua %ResultSet.

    Query FindByAge(pMinAge As %Integer) As %SQLQuery
{
    SELECT %ID, Name, Age
    FROM MyApp.Person
    WHERE Age >= :pMinAge
    ORDER BY Age
}

; Cách dùng
SET rs = ##class(MyApp.Person).FindByAgeFunc(25)
WHILE rs.%Next() {
    WRITE rs.%Get("Name"), " - ", rs.%Get("Age"), !
}

    🖥️ Terminal Snippets¶

    ; Liệt kê tất cả property của một class
SET props = ##class(%Dictionary.ClassDefinition).%OpenId("MyApp.Person").Properties
FOR i=1:1:props.Count() { WRITE props.GetAt(i).Name, ! }

; Kiểm tra property có Required không
SET propDef = ##class(%Dictionary.PropertyDefinition).%OpenId("MyApp.Person||Name")
WRITE propDef.Required, !

; Gọi ClassMethod và đọc Parameter
WRITE ##class(MyApp.Config).#VERSION, !

    1. Properties¶

    Represent the data fields of a class.

    /// Basic types
Property Name      As %String(MAXLEN = 100) [ Required ];
Property Age       As %Integer;
Property Score     As %Numeric(SCALE = 2);
Property IsActive  As %Boolean [ InitialExpression = 1 ];
Property CreatedAt As %TimeStamp;

/// Collections
Property Tags      As List Of %String;
Property Scores    As Array Of %Integer;

/// Object reference (embedded Serial)
Property Address   As MyApp.Address;

/// Object reference (linked Persistent — stored as foreign key)
Property Manager   As MyApp.Employee;

    Property Keywords (inside [ ])¶

    Keyword Effect
    Required Cannot be empty — %Save() will fail if not set
    InitialExpression Default value when %New() is called
    Calculated No storage — value computed by Get/Set methods
    Transient No storage — in-memory only, not persisted
    ReadOnly Can be read but not set from outside
    Private Not accessible outside the class
    Internal Hidden from class documentation

    Property Parameters (inside ( ))¶

    Parameter Applies to Effect
    MAXLEN %String Max length (default 50, use 0 for unlimited)
    SCALE %Numeric Decimal places
    MINVAL, MAXVAL %Integer, %Numeric Range validation
    VALUELIST %String Comma-separated allowed values
    PATTERN %String Regex-like pattern validation
    XMLNAME Any Override XML element name
    JSONNAME Any Override JSON field name 
    Property Status As %String(VALUELIST = ",active,inactive,pending") [ Required ];
Property Email  As %String(MAXLEN = 200, PATTERN = ".+@.+\..+");

    Collection Properties¶

    Property Tags As List Of %String;

; Usage
SET obj = ##class(MyApp.Person).%New()
DO obj.Tags.Insert("developer")
DO obj.Tags.Insert("iris")
WRITE obj.Tags.Count(), !        ; 2
WRITE obj.Tags.GetAt(1), !       ; developer
DO obj.Tags.RemoveAt(1)

    Property Config As Array Of %String;

; Usage
SET obj.Config.SetAt("value1", "key1")
WRITE obj.Config.GetAt("key1"), !

    2. Methods¶

    /// Instance method — called on an object instance
Method Greet(pPrefix As %String = "Hello") As %String
{
    RETURN pPrefix _ ", " _ ..Name _ "!"
}

/// ClassMethod — called on the class itself (no instance needed)
ClassMethod Create(pName As %String, pAge As %Integer) As MyApp.Person
{
    SET obj = ##class(MyApp.Person).%New()
    SET obj.Name = pName
    SET obj.Age  = pAge
    RETURN obj
}

    Method vs ClassMethod¶

    Method ClassMethod
    Called on Instance: obj.Greet() Class: ##class(X).Create()
    Access .. (self) ✅ ❌
    Typical use Business logic on an object Factory, utilities, queries

    Callback Methods (Lifecycle Hooks)¶

    Override these to hook into object lifecycle:

    /// Called by %New() — constructor
Method %OnNew(pArg As %String) As %Status
{
    SET ..CreatedAt = $NOW()
    RETURN $$$OK
}

/// Called before %Save() — return error to prevent save
Method %OnBeforeSave(insert As %Boolean) As %Status
{
    IF ..Name = "" { RETURN $$$ERROR($$$GeneralError, "Name required") }
    RETURN $$$OK
}

/// Called after %Save()
Method %OnAfterSave(insert As %Boolean) As %Status
{
    RETURN $$$OK
}

/// Called before %DeleteId()
ClassMethod %OnDelete(oid As %ObjectIdentity) As %Status
{
    RETURN $$$OK
}

    3. Parameters¶

    Constants defined at the class level — fixed at compile time, not per-instance.

    Class MyApp.Config Extends %Registered
{
    Parameter VERSION = "1.0.0";
    Parameter MAX_RETRY As %Integer = 3;
    Parameter TIMEOUT As %Integer = 30;
}

; Access from within the class:
WRITE ..#VERSION, !

; Access from outside:
WRITE ##class(MyApp.Config).#VERSION, !
WRITE $PARAMETER("MyApp.Config", "VERSION"), !

    💡 Parameters are often used in %CSP.REST subclasses to configure behaviour:
    Parameter CONTENTTYPE = "application/json";

    4. Indices¶

    Tell IRIS how to build lookup structures for SQL queries. See indices.md for full detail.

    /// Standard index on Name
Index NameIdx On Name;

/// Unique index — enforces uniqueness
Index EmailIdx On Email [ Unique ];

/// Composite index
Index NameAgeIdx On (Name, Age);

/// Bitmap index — for low-cardinality fields (boolean, status...)
Index StatusIdx On Status [ Type = bitmap ];

    5. XData Blocks¶

    Embedded XML/JSON data stored inside a class — used for configuration, URL maps, etc.

    XData UrlMap [ XMLNamespace = "http://www.intersystems.com/urlmap" ]
{
<Routes>
  <Route Url="/people" Method="GET" Call="GetAll"/>
</Routes>
}

XData DefaultData
{
<list>
  <item>value1</item>
</list>
}

    6. Queries¶

    Named SQL queries defined as part of the class — callable via %ResultSet.

    Query FindByAge(pMinAge As %Integer) As %SQLQuery
{
    SELECT %ID, Name, Age
    FROM MyApp.Person
    WHERE Age >= :pMinAge
    ORDER BY Age
}

; Usage
SET rs = ##class(MyApp.Person).FindByAgeFunc(25)
WHILE rs.%Next() {
    WRITE rs.%Get("Name"), " - ", rs.%Get("Age"), !
}

    🖥️ Terminal Snippets¶

    ; List all properties of a class
SET props = ##class(%Dictionary.ClassDefinition).%OpenId("MyApp.Person").Properties
FOR i=1:1:props.Count() { WRITE props.GetAt(i).Name, ! }

; Check if property is required
SET propDef = ##class(%Dictionary.PropertyDefinition).%OpenId("MyApp.Person||Name")
WRITE propDef.Required, !

; Call a ClassMethod
WRITE ##class(MyApp.Config).#VERSION, !
