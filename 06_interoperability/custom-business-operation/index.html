    Custom Business Operation¶

    Exam Domain: T1 · Architecture — thiết kế và coding Business Operation gửi data ra external system

    Overview¶

    Business Operation (BO) là component gửi dữ liệu ra hệ thống bên ngoài (database, HTTP endpoint, file, HL7...). BO nhận message từ Business Process qua Message Queue, xử lý, và optionally trả về response.

    [Business Process]
      ↓ Ens.Request
[Business Operation]  ← OnMessage() xử lý tại đây
      ↓ (Outbound Adapter)
[External System]

    Class Structure¶

    Class MyApp.BO.EmailSender Extends Ens.BusinessOperation
{

Parameter ADAPTER = "EnsLib.HTTP.OutboundAdapter";

/// Entry point — được gọi bởi Production khi nhận message
Method OnMessage(pRequest As MyApp.Msg.EmailRequest, Output pResponse As Ens.Response) As %Status
{
    SET tSC = ..ValidateRequest(pRequest)
    IF $$$ISERR(tSC) { RETURN tSC }

    RETURN ..SendEmail(pRequest)
}

/// Helper — validate input trước khi gọi downstream
Method ValidateRequest(pRequest As MyApp.Msg.EmailRequest) As %Status
{
    IF pRequest.To = "" { RETURN $$$ERROR($$$GeneralError, "Missing recipient") }
    RETURN $$$OK
}

/// Helper — giao tiếp với downstream system
Method SendEmail(pRequest As MyApp.Msg.EmailRequest) As %Status
{
    // Dùng ..Adapter để gọi HTTP, SMTP, TCP...
    RETURN $$$OK
}

}

    Best Practices¶

    # Practice Chi tiết
    1 Viết Message class trước Viết Ens.Request / Ens.Response trước khi viết BO — IDE autocomplete giúp tránh typo
    2 Tách nhiều method OnMessage() chỉ điều phối — logic cụ thể nằm trong helper methods
    3 Response không bắt buộc Không phải lúc nào cũng cần return message — tùy adapter và downstream
    4 Luôn check %Status Kiểm tra mọi status, handle error phù hợp — IRIS sẽ retry nếu BO trả về lỗi
    5 Dùng Record Mapper cho CSV Với file delimited (CSV), dùng Record Mapper thay vì tự parse
    6 Dùng class có sẵn cho HL7 Dùng EnsLib.HL7.Operation.TCPOperation để gửi HL7 V2 qua TCP

    Common Adapters¶

    Adapter Dùng khi
    EnsLib.HTTP.OutboundAdapter Gọi REST/HTTP API
    EnsLib.File.OutboundAdapter Ghi file ra filesystem
    EnsLib.SQL.OutboundAdapter Ghi vào external database
    EnsLib.HL7.Operation.TCPOperation Gửi HL7 V2 qua TCP (class sẵn có)
    (không có adapter) Logic thuần ObjectScript (gọi class trực tiếp)

    Key Points¶

    • ✅ OnMessage() là entry point duy nhất — IRIS gọi method này khi có message mới
    • ✅ Tách helper methods để dễ test và tái sử dụng
    • ✅ ..Adapter là reference đến adapter instance — dùng để gọi downstream system
    • ⚠️ Nếu OnMessage() trả về lỗi ($$$ISERR), IRIS sẽ retry theo cấu hình — tránh side effect trùng lặp
    • ⚠️ Response (pResponse) là Output parameter — phải SET chứ không phải RETURN
    • 💡 Dùng EnsLib.HL7.Operation.TCPOperation thay vì tự viết cho HL7 — đã handle framing và retry
