    Local Development Setup¶

    Hướng dẫn này giúp bạn chạy môi trường IRIS học tập trên máy local bằng Docker và kết nối VS Code.

    Prerequisites¶

    Công cụ Phiên bản Link
    Docker Desktop ≥ 4.x docker.com
    VS Code ≥ 1.80 code.visualstudio.com
    InterSystems ObjectScript extension Latest VS Code Marketplace
    InterSystems Server Manager extension Latest VS Code Marketplace

    Step 1 — Start IRIS Container¶

    File docker-compose.yml đã có sẵn ở root của repo:

    services:
  iris:
    image: intersystemsdc/iris-community:latest
    container_name: iris-dev
    ports:
      - "1972:1972"    # SuperServer port (ObjectScript connection)
      - "52773:52773"  # Web port (Management Portal + REST)
    environment:
      - IRIS_USERNAME=_SYSTEM
      - IRIS_PASSWORD=SYS
    volumes:
      - iris-data:/durable  # Persistent data — data không mất khi restart container

volumes:
  iris-data:

    Chạy lệnh:

    docker compose up -d

    Kiểm tra container đang chạy:

    docker ps

    Bạn sẽ thấy iris-dev với status Up.

    ⏳ Lần đầu chạy có thể mất 1–2 phút để pull image và khởi động IRIS.

    Step 2 — Verify Management Portal¶

    Mở trình duyệt → truy cập:

    http://localhost:52773/csp/sys/UtilHome.csp

    Đăng nhập:
    Username _SYSTEM
    Password SYS
    Namespace USER

    Nếu thấy trang Management Portal → IRIS đang chạy bình thường.

    Step 3 — Connect VS Code¶

    File .vscode/settings.json đã được cấu hình sẵn:

    {
    "intersystems.servers": {
        "local": {
            "webServer": {
                "scheme": "http",
                "host": "localhost",
                "port": 52773
            },
            "username": "_SYSTEM",
            "description": "Local IRIS instance (Docker)"
        }
    },
    "objectscript.conn": {
        "server": "local",
        "ns": "USER",
        "active": true
    }
}

    Sau khi clone repo và start container:

    1. Mở repo trong VS Code
    2. VS Code tự đọc .vscode/settings.json và kết nối tới server local
    3. Khi được hỏi password → nhập SYS
    4. Kiểm tra status bar ở góc dưới trái VS Code — sẽ thấy USER (namespace đang kết nối)

    💡 Nếu không thấy status bar IRIS: nhấn Ctrl+Shift+P → ObjectScript: Toggle Connection

    Step 4 — Open IRIS Terminal¶

    Mở terminal trực tiếp vào IRIS từ command line:

    docker exec -it iris-dev iris session iris -U USER

    Test nhanh:

    WRITE "Hello IRIS!", !
WRITE $ZVERSION, !

    Thoát terminal:

    HALT

    Common Commands¶

    # Khởi động
docker compose up -d

# Dừng (giữ data)
docker compose stop

# Dừng và xóa container (giữ volume data)
docker compose down

# Dừng và xóa cả data (reset hoàn toàn)
docker compose down -v

# Xem logs
docker logs iris-dev -f

# Mở IRIS Terminal
docker exec -it iris-dev iris session iris -U USER

    Compile & Run ObjectScript¶

    Compile một file .cls từ IRIS Terminal:

    DO $SYSTEM.OBJ.Load("/path/to/MyClass.cls", "ck")

    Chạy exercise:

    DO ##class(Exercises.ObjectScriptBasics).Run()

    Chạy unit test:

    DO ##class(%UnitTest.Manager).RunTest("MyApp.Test.PersonTest")

    Troubleshooting¶

    Vấn đề Nguyên nhân Giải pháp
    localhost:52773 không mở được Container chưa chạy docker compose up -d
    VS Code không kết nối Password sai hoặc server chưa ready Chờ 30s sau khi start, nhập lại password SYS
    Port 52773 bị conflict Có app khác dùng port Đổi port trong docker-compose.yml và settings.json
    Data mất sau khi down Dùng down -v Dùng docker compose stop thay vì down để giữ volume
