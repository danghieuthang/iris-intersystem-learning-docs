    05 · REST API¶

    Exam Domain: T3 · Data Retrieval — xây dựng REST services với %CSP.REST, %JSON.Adaptor, và hai cách tiếp cận Specification-first vs Manual Coding

    Overview¶

    IRIS hỗ trợ hai cách tiếp cận để xây dựng REST API:

    Cách Mô tả Khi dùng
    Manual Coding Tự viết Dispatch Class kế thừa %CSP.REST, định nghĩa UrlMap thủ công Đơn giản, nhanh, project nhỏ
    Specification-first Viết OpenAPI spec (.yaml/.json) trước → IRIS tự sinh Dispatch Class và Implementation Class API chuẩn hóa, team lớn, cần documentation

    Dù theo cách nào, flow vẫn là:

    HTTP Request → CSP Web Application → Dispatch Class (UrlMap) → ClassMethod → Response

    Manual Coding — Dispatch Class¶

    Mỗi REST endpoint là một ClassMethod trả về %Status. HTTP status code set qua %response.Status, không phải return value.

    Class MyApp.REST.Dispatch Extends %CSP.REST
{

Parameter CONTENTTYPE = "application/json";

XData UrlMap [ XMLNamespace = "http://www.intersystems.com/urlmap" ]
{
<Routes>
  <Route Url="/people"       Method="GET"    Call="GetAll"/>
  <Route Url="/people/:id"   Method="GET"    Call="GetOne"/>
  <Route Url="/people"       Method="POST"   Call="Create"/>
  <Route Url="/people/:id"   Method="PUT"    Call="Update"/>
  <Route Url="/people/:id"   Method="DELETE" Call="Delete"/>
</Routes>
}

ClassMethod GetAll() As %Status
{
    SET result = []
    // ... populate array
    WRITE result.%ToJSON()
    RETURN $$$OK
}

ClassMethod GetOne(id As %String) As %Status
{
    SET person = ##class(MyApp.Person).%OpenId(id)
    IF person = "" {
        SET %response.Status = "404 Not Found"
        RETURN $$$OK
    }
    DO person.%JSONExport()
    RETURN $$$OK
}

}

    JSON Handling¶

    IRIS có built-in JSON support qua dynamic objects {} và [].

    // Tạo object và array
SET obj = {}
SET obj.name = "Alice"
SET obj.age = 30

SET arr = []
DO arr.%Push(obj)

// Serialize → string/stdout
WRITE obj.%ToJSON()

// Deserialize từ string
SET obj = {}.%FromJSON(jsonString)

// Đọc request body
SET body = {}.%FromJSON(%request.Content)
WRITE body.name

    %JSON.Adaptor¶

    Thêm %JSON.Adaptor vào class để tự động serialize/deserialize toàn bộ object mà không cần code thủ công.

    Class MyApp.Person Extends (%Persistent, %JSON.Adaptor)
{
    Property Name As %String;
    Property Age As %Integer;
}

// Serialize → stdout
SET person = ##class(MyApp.Person).%OpenId(1)
DO person.%JSONExport()

// Deserialize vào object mới
SET person = ##class(MyApp.Person).%New()
DO person.%JSONImport(jsonString)
DO person.%Save()

    Web Application Setup¶

    Bước Nơi thực hiện Chi tiết
    Tạo Web App Management Portal → Security → Web Applications Đặt Path prefix (VD: /api/myapp)
    Chỉ định Dispatch Class Cùng trang Dispatch Class = MyApp.REST.Dispatch
    Authentication Cùng trang Password / Unauthenticated tuỳ use case
    CORS Tab CORS Enable nếu frontend gọi từ domain khác

    Specification-first Approach¶

    Thay vì viết code trước, viết OpenAPI 2.0 spec (.yaml hoặc .json) trước, sau đó dùng IRIS để sinh code.

    Các bước: 1. Viết file OpenAPI spec định nghĩa toàn bộ endpoints, request/response schema 2. Management Portal → System → API Management → Import spec 3. IRIS tự sinh: - Dispatch Class — handle routing (không cần sửa) - Implementation Class — chứa stub methods → bạn viết logic vào đây 4. Khi update spec, re-import sẽ cập nhật Dispatch Class mà không xóa logic trong Implementation Class

    OpenAPI Spec (.yaml)
      ↓ Import vào IRIS
Dispatch Class (auto-generated, không sửa)
      ↓ delegate
Implementation Class (bạn viết logic ở đây)

    💡 Specification-first là cách được khuyến nghị cho project thực tế — API contract rõ ràng trước khi code, có sẵn Swagger UI để test.

    InterSystems API Manager (IAM)¶

    IAM là API gateway của InterSystems, cung cấp: - Rate limiting, authentication, logging ở tầng gateway - Developer portal với Swagger UI - Analytics và monitoring

    ⚠️ IAM chỉ có trên môi trường Production — không được bundled trong IRIS Community Edition hay Docker image thông thường. Không thể test IAM trên local dev setup. Với kỳ thi, hiểu khái niệm là đủ.

    Key Points¶

    • ✅ RETURN $$$OK luôn ở cuối method— không return HTTP status
    • ✅ HTTP status set qua SET %response.Status = "404 Not Found"
    • ✅ Request body đọc qua %request.Content
    • ✅ Specification-first: IRIS sinh Dispatch Class từ OpenAPI spec; bạn chỉ viết logic trong Implementation Class
    • ⚠️ Web Application phải được tạo trước — không tự có khi deploy class
    • ⚠️ CORS không bật mặc định — cần enable trong Management Portal nếu gọi từ browser
    • ⚠️ IAM (API Manager) không có trên local/Community Edition — chỉ Production
    • 💡 Dùng %JSON.Adaptor thay vì build JSON thủ công để tránh lỗi và giảm code

    🖥️ Terminal Snippets¶

    // --- Test REST endpoint từ Terminal (không cần HTTP) ---
SET sc = ##class(MyApp.REST.Dispatch).GetAll()
WRITE $SYSTEM.Status.GetErrorText(sc), !

// --- Serialize object sang JSON string ---
SET person = ##class(MyApp.Person).%OpenId(1)
SET writer = ##class(%JSON.Writer).%New()
DO writer.RootObject(person)

// --- Parse JSON string ---
SET json = "{""name"":""Alice"",""age"":30}"
SET obj = {}.%FromJSON(json)
WRITE obj.name, !
